# One line

1本の光る線とカメラの移動だけで場面をつなぐ、ナレーションなしのプロダクト動画スタイル。マスコットの叩きつけで始まり、線の上への着地で終わる。全フレームと音をコードで生成する。

|役割|指定|
|---|---|
|背景|#FBFCFD、淡い丸 #EAF1F6 を視差で流す、細かい粒子ノイズ|
|文字|#273B4B|
|線・主要な面|#344F69、外側に #5B7F9F の淡いにじみ、先端に白く光る点|
|強調語|#5B7F9F|
|取り消し・注意|#F4A9B8|
|日本語|Zen Maru Gothic。見出しBold、本文Medium|
|字幕|英語、白い角丸の帯、見出しが出ている間だけ|
|動き|カメラは移動0.7秒前後のease in-out、着地はバネ（押しつぶし→戻り）、出現はback ease、数字はカウントアップ|
|音|100 BPM・Dメジャーのマレット＋パッド、中盤からビート、移動にwhoosh、出現にpop、着地にimpact、4音ファンファーレ。-14 LUFS|
|形|16:9のPV、または9:16の機能ショート（駅を縦に積む、下部400pxは空ける）|

参考：Duolingo spec ad prompt "The Path"（構成のみ）。色・キャラクター・コピーは作品ごとに置き換える。
