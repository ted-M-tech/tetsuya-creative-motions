# Web制作記録テンプレート

このファイルを作品のディレクトリへコピーし、未確認項目は未確認と記入します。サンプルを実績として公開しないでください。

## 完成物と目的

作品名 / 公開URL / 対象者 / 行動してほしいこと / 現行仕様の根拠 / 予定との区別。

## 実装の再現

リポジトリURL / 固定commitまたはtag / Node版 / パッケージマネージャー版 / lockfile / 作業ディレクトリ / install・check・build・previewコマンド / 必要素材 / 外部サービスの要否。

## 制作の再現

- 原文のプロンプト：公開してよい指示のみ。日時と対象工程を添える。
- 再構成プロンプト：完成形からまとめ直した指示と明記。
- 修正の判断：課題 → 変更 → 理由 → 確認結果。
- 使用モデル：確認できる識別子と設定。不明なら不明。
- 使用スキル：公式URL、版またはcommit、ローカル変更、実際に読んだファイルのSHA-256、工程、採否。記録例は隣のskills.lock.example.json。

## 素材と権利

素材ごとの原URL、作者、ライセンス、変更内容。第三者スキル・写真・商標・音声を自作コードのライセンスに含めない。

## 検証と公開

実行コマンドと結果 / 検証したviewportとブラウザ / 読み込み・リンク・改行・操作・reduced motion / 未検証事項 / 公開日時とソースrevision。

## 再現できること・できないこと

固定ソースを動かす条件と、AI出力・外部API・素材の再配布上の限界を具体的に記す。
