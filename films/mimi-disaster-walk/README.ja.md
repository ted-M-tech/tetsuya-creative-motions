# Pronunciation Disasters 8 - Walk / Work

[English](README.md)

Lanclo SNS ショート #049（シリーズ「Pronunciation Disasters / 発音で大事故」第8話）。19.9秒、1080×1920、60fps、2カット（日本語のみ／英語字幕つき）。

場面：日曜のBBQ。ホストのブルーノに「どうやって来たの？」と聞かれ、友だちが得意げに「I walked!（歩いて来た）」→ r の響きが入って「I worked!（働いてきた）」に。ブルーノ「日曜に仕事!?」と同情の涙。Mimiはネクタイとカバンで飛び出す。

構成はシリーズのテンプレート（[mimi-disaster-sit](../mimi-disaster-sit/)、ソースは第6話 [mimi-disaster-peace](../mimi-disaster-peace/) からコピー）：1フレーム目にMimiのオチ（「それ、「働いてきた」に聞こえてる！」）→ 巻き戻し → 状況フック → 言い間違い → フリーズ → Mimi → 自分の声の2テイク比較カード＋口の形（/ɔː/ と /ɜːr/）→ 実際のLanclo画面 → 言い直し → エンドカード＋CTAタップ。今回は下品な単語ではないので伏せ字なし。

- 声：学習者テイクとお手本はオーナーの登録済みLanclo音声（ownvoice.py）。WAVは生体データなのでGitに入れず、Drive `049. Pronunciation Disasters 8 - Walk or Work/Disasters8_Walk_assets/own-voice/` に保管。ブルーノはKokoro英語（am_michael）。
- 言い間違いの確認はフォルマント測定（Whisperではない）：学習者の worked の母音は F3 ≈ 1700–1850 Hz（r の響きあり）、お手本の walked は F3 ≈ 2800 Hz（r なし）。
- Mimiの一人称は「僕」。言い間違えるのは「友だち」、他の役は共通サブキャストのブルーノ。
