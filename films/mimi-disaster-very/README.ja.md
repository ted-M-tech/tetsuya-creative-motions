# Pronunciation Disasters 14 - Very / Berry

[English](README.md)

Lanclo SNS ショート #056（シリーズ「Pronunciation Disasters / 発音で大事故」第14話）。18.8秒、1080×1920、60fps、2カット（日本語のみ／英語字幕つき）。完成版（2026-10-23、オーナー承認済み）。

場面：晴れた街角の果物屋さん。Mimiが店員役（緑のストライプのエプロン）で友だちにいちごを1つ手渡す。友だちは「Thank you very much!」とお礼を言うが、カタカナの「ベリー」は “Thank you *berry* much!” に聞こえ、店員Mimiは注文と受け取っていちごをどんどん積み、友だちはいちごに埋もれる（シーン…、“More berries!”）。素に戻ったMimiが指さして「それ「いちご」に聞こえてる〜！！」。下品さなしのビジュアルギャグ。

構成はパイロット（[mimi-disaster-sit](../mimi-disaster-sit/)）と同じ：1フレーム目にフック（「Thank you ベリーマッチ🍓」、いちごは絵）→ 巻き戻し → 状況フック → 言い間違い → フリーズ（レコードスクラッチ、ドサドサッ、シーン…）→ Mimiが飛び出す → 自分の声の2テイク比較カード（V＝上の歯を下唇に軽く当てて声を出す／B＝両唇を閉じる、正面と横の図）→ 実際のLanclo画面 → 言い直し → エンドカード＋CTAタップ。

- 声：学習者テイクとお手本はオーナーの登録済みLanclo音声（ownvoice.py）。WAVはGitに入れず、Drive `056. Pronunciation Disasters 14 - Very or Berry/Disasters14_Very_assets/own-voice/` に保管。サブキャストの声なし。
- キャスト：Mimi（店員の衣装でも登場）と友だち（言い間違える役）のみ。Mimiの一人称は「僕」（今回は一人称のセリフなし）。
