## 見どころ

- 人物カードが積み重なり、似た声を探す悩みが「自分の声」という解決につながる。
- 研究結果は同じゼロ起点の棒グラフ。強調するのは得点の伸びの差。
- 夜のニュース収集から、朝の英語教材までを一連の動きで見せる。
- Language CloneからLancloへ文字が縮約するブランドエンディング。
