# ネイティブの声でシャドーイング、もうやめた

[English](README.md) · **日本語**

1フレーム目からフック「ネイティブの声でシャドーイング、もうやめた。」、Mimiが知らない人の顔のカセットをポイッ。これまで：クマのブルーノ（いつものサブキャラ。知らないネイティブ役）が速く "Please leave the light on."、Mimiは学習者なまりで必死に追いかける——2本の声のレーンが合わない（ズレズレ…／「声もリズムも別人。どこを真似すれば…？」）。コピー「お手本は、自分の声で。」→ 実アプリのデイリーレッスン（"Please leave the light on." と「お手本」ボタン＝自分のAIボイスのお手本）→ いま：自分の声のお手本に、同じ声でシャドーイング。レーンがそろう（ぴったり！／「同じ声だから、違うのは発音だけ」）→「知らない誰かより、未来の自分。」→ エンドカード。研究の数字は使わない。4本目「自分の声、むり」とは別の、短い対比の1本。
