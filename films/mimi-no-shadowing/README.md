# I Stopped Shadowing Native Speakers

**English** · [日本語](README.ja.md)

From frame 1 the hook card says 「ネイティブの声でシャドーイング、もうやめた。」 while Mimi tosses away a cassette with a stranger's face on it (ポイッ!). The old way: a native stranger (Bruno the bear, from the recurring side cast) says "Please leave the light on." fast, and Mimi chases it in a Japanese-learner accent — two voice lanes that never line up (ズレズレ…, 「声もリズムも別人。どこを真似すれば…？」). Copy 「お手本は、自分の声で。」, then the real daily lesson: "Please leave the light on." and its 自分のAIボイスのお手本 button. The new way: the model in Mimi's own voice and Mimi shadowing it in the same voice — the lanes match (ぴったり！, 「同じ声だから、違うのは発音だけ」). Close: 「知らない誰かより、未来の自分。」 No research numbers; kept as a quick contrast, unlike [My own voice? No way](../mimi-jibun-no-koe/README.md) (#4).
