# 統合プロンプト（完成形から逆算した指示。最初の入力の原文ではない）

Lanclo のシリーズ「How Do You Say It?」第3話を、Mimi ショート（2D 公式絵柄・縦 1080×1920・60fps・約17秒）で作る。第2話（films/mimi-say-otsukare）の source/ を写し、ビートの id と作成機能の撮り方（本物の API を叩く → 撮影専用パッチ → capture.sh → app_track）はそのまま。テーマは「いただきます」：英語に決まったひと言はなく、場面で言う。"I will receive" は「受け取ります」に聞こえる。キャストは Mimi と友だちの2人だけ。

1. 0–1.5秒：1フレーム目からフック「いただきます、英語で？」と「How Do You Say It? #3」。夕ごはんの食卓（ライブラリの dining）で、友だちがお茶わんを持ち、Mimi はわくわく。
2. 1.5–3.05秒：友だち（オーナーの声・学習者、ふつうに明るく）"I will receive!"。
3. 3.05–4.3秒：Mimi 困惑、吹き出し「Receive… what?」（声なし）、字幕「“I will receive” は「受け取ります」」。
4. 4.3–10.95秒：実アプリ（シミュレーター、QA フィクスチャ）。「食べる前のいただきます」を入力 → フレーズを作成 → 表現を考えています… → フレーズを確認（"Let's eat!" と例文）→ 保存 → マイノートに保存したよ。字幕「日本語のまま打てばOK」「例文つきで出る」「保存は自分で」。結果は大きなラベルでも見せる。答えと例文は Lanclo の本物のサーバー処理がこの入力に返したもの（撮影専用パッチで表示）。
5. 10.95–14.25秒：Mimi のカード「いただきます」→ 食べはじめる "Let's eat!"（アプリの答え）/ 作ってくれた人に "This looks great!"（よく言うひと言）。2つともオーナーの声・US。字幕「英語は場面で言う」。
6. 14.25–16.05秒：食卓に戻り、友だちが "Let's eat!"（吹き出し＋同じ声）、Mimi はごはんに飛び込む。字幕「次は何を英語にしたい？」。
7. 16.05秒〜：エンドカード、CTA タップ「ぽちっ」。

見た目はシリーズと同じ（色・書体・大きさ・カードの形）。音：声が主、テーマ BGM は声の下、SFX は小さく、-14 LUFS（トゥルーピーク -1.5 dBTP 以下）。画面：下 420px（y>1500）に意味のあるものを置かない、英語字幕は y 1500 より上・x 60–880、右のアクション列（x>900, y 820–1520）に文字・吹き出し・小さい Mimi を置かない、上の文字は y 200 から。
