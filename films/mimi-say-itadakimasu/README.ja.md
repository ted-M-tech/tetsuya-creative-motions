# How Do You Say It? 3 — いただきます

[English](README.md) · **日本語**

機能紹介シリーズ「How Do You Say It?」の第3話（型は[第1話](../mimi-say-yoroshiku/README.ja.md)・[第2話](../mimi-say-otsukare/README.ja.md)）。夕ごはんの食卓で、友だちがお茶わんを持っていただきますを直訳して "I will receive!"。Mimi は「Receive… what?」と困惑。アプリで「食べる前のいただきます」と日本語のまま打ち、「フレーズを作成」で作成機能の本物の答え "Let's eat!"（いただきます（食事を始めるときのあいさつ））と本物の例文 "Everything looks so delicious, let's eat!" が出る。友だちが保存。Mimi のカード：食べはじめる "Let's eat!"（アプリの答え）/ 作ってくれた人に "This looks great!"（よく言うひと言）。友だちが言い直して、締めは「次は何を英語にしたい？」。
