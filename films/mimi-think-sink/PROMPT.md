# 再制作用の統合プロンプト — 「think が sink に」

完成版の判断を1つの指示にまとめたものです。最初に入力した原文ではありません（経過は [PROCESS.md](PROCESS.md)）。共通キット [kits/mimi-short](../../kits/mimi-short/README.md) を使う前提です。別の話で作るときは **[置き換える]** を差し替えてください。

---

LancloのマスコットMimiが主役の、15秒の縦型ショート（1080×1920、60 fps、Instagram Reels / TikTok）を、承認済みの2Dイラストの絵柄のまま、共通キット `kits/mimi-short` で作る。ナレーションなし。日本語の字幕は画面上部、下端約400 pxは空ける。

## 話（[置き換える：言い間違いと見立て]）

**ありがちな言い間違いを、文字どおりの物で見せる。** think を sink と言うと、シンクが落ちてくる。言うたびに増える → Lancloで自分の声の正しい発音を聴く → 直すポイントは1つ → 練習 → 物が消えて言える。

| 秒 | 画面 | 字幕／音 |
|---|---|---|
| 0–1.0 | 得意げなMimi（ウインク、人差し指）。0.05秒からシンクが画面上から落ち、0.45秒に着地して弾む | 「“I sink so!”」（大きく、sinkは赤）／声 "I sink so!"、着地で金属音 |
| 1.0–2.2 | ぼうぜん（汗、耳がピン、ぷるぷる）。もう一度言うと1.8秒に2台目が積み重なる | 「think のつもりが／sink＝流し台!?」／自信なさげな2回目、金属音 |
| 2.2–2.9 | スマホに手を伸ばして録音をタップ（2.63秒） | タップ音 |
| 2.9–4.4 | 聴く。スマホに「自分の声のお手本」と波形 | 「自分の声が／“I think so.”」、「▶ 自分の声のお手本」ラベル／自分の声の正しい "I think so." |

| 6.8–9.0 | お手本と一緒に話す（口パクは声の音節に合わせる） | 「お手本に合わせて、言ってみる。」、「● お手本と一緒に話す」／お手本の声と重ねて Mimi の "I think so." |

## 絵

- 新しく要るものだけCodexで描く（公式PNGとライブラリのポーズを添付、同じ絵柄・向き・縮尺・白背景・文字なし）：得意げ（ウインク、人差し指を立てる、片手を腰）、ぼうぜん（丸い目、小さな「o」の口、両耳がピン、汗、ショックの線）、小道具のシンクと電球（キャラなし、同じ線の太さ）。原文は [prompts/01-codex-poses-and-props.txt](prompts/01-codex-poses-and-props.txt)。
- 切り抜き（電球は光の縁を消すため `FUZZ=30`）。頭の大きさがそろうよう高さを決める（得意げ 1000、ぼうぜん 1180）。
- 作品の承認後に Lanclo の `design/mimi-2d` へ PR で追加し、キットへ同期する。

## 動き

- 既存の演技（reach、listen、perk、think、jump、success）はライブラリのまま。足りない演技だけ作品側で作る：得意げ（反って、指を言葉に合わせて振る、弾む）、ぼうぜん（着地の衝撃でびくっ、細かい震え、2台目でもう一度）、話す（声の音節で口を開く、最後にうなずく）。
- 小道具は編集（HTML）側で落とす・弾ませる・消す。Riveには入れない。

## 編集と音

- キットの見た目（字幕、ラベル、スマホUI、レーダーカード、エンドカード）をそのまま使う。
- 声はKokoro（`af_heart`）で2本："I sink so!" と "I think so."。正しいほうを「自分の声のお手本」として使う。
- 効果音とBGMはキット（`sfx.Mix`）。合図の時刻は `mix.py` と `index.html` で同じにする。
