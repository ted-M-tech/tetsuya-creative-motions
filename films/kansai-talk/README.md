# 中の人トーク — 関西人2人のリアルな会話。

作り込んだ例文ではなく、二人の会話を聞き取る体験に。最初に挑戦のルールを短く示し、キャラクターと大阪の風景で世界観をつなぎます。

## 再制作の流れ

1. 聞き取りの挑戦を冒頭で一言で伝える。
2. 人の会話を素材にし、音声を無理に速めない。
3. 同じシリーズの背景・キャラクター・字幕の体系を使う。
4. 音声の実測時間に字幕と動きを合わせる。別の題材で作る場合は、台本・声・キャラクターを自分が利用できるものに置き換える。
5. 9:16の画面で文字の欠け、字幕の先走り、音声の途切れを確認する。

## 記録の範囲

完成物からの再構成を含みます。元の全会話ログや完全な制作環境の公開ではありません。
