# 再制作用の統合プロンプト — 「積読」（デイリーレッスン・実画面）

完成版の判断を1つの指示にまとめたものです。最初に入力した原文ではありません（経過は [PROCESS.md](PROCESS.md)）。実画面の回の共通手順は [mimi-shashin/PROMPT.md](../mimi-shashin/PROMPT.md)。

---

LancloのマスコットMimiが**実際のLancloアプリでデイリーレッスンをする**15秒の縦型ショート（1080×1920、60 fps）を作る。アプリの画面は本物（シミュレーター、`--uitesting --visual-fixtures --qa-*`、個人データなし）、Mimiは承認済みの2Dの絵柄で画面の横に立つ。

## 1. 画面を録る

1. 操作手順のテスト（`DescribeUITests` クラスの `testDailyWalkthrough`）：日本語で起動 → ホーム → 今日のタスクの「デイリーレッスン」 → お手本 → 録音 → 採点までスワイプ → 次へ。各画面で止める。
2. `kits/mimi-short/app-capture/capture.sh` で録画、`cut.sh` で60 fpsにそろえてから切る。
3. デモデータでは録り直した後の採点がエラーになる。録り直す前の画面だけで組む。
4. デモデータの「QA用データ」という文字は、画面上に白い目隠しを置いて隠す。

## 2. 話

| 秒 | 画面 | 字幕／音 |
|---|---|---|
| 0–2.0 | しょんぼりしたMimiの横で本の山が伸び、1.4秒で崩れる | 「英語の本、増えるだけ…」→「積読。」 |
| 2.0–3.4 | スマホが右から入る。ホームの「デイリーレッスン」をタップ | 「やることは、毎日アプリが決める。」 |
| 3.4–5.6 | 今日の一文に寄る。自分の声のお手本 "Please leave the light on." | 「自分の声が、ネイティブ発音のお手本に。」、▶ 自分の声のお手本 |

| 11.8–14.0 | Mimiが跳んで喜ぶ | 「1日10分、自分の声で。」 |

## 3. 組み方

- 本の山は新しい小道具（[prompts/01-codex-book-tower.txt](prompts/01-codex-book-tower.txt)）。動きは編集側：下からの切り抜きで段々に伸ばし、揺れて、回転しながら落ちる。
- Mimiは平らな背景で書き出して縮小し、スマホの横へ。スマホは時間指定のない入れ物。
- 声はアプリのデモの一文に合わせる。言い間違いはL/Rの1語だけにする。
