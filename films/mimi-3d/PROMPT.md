# 再制作用の統合プロンプト — 2Dマスコットをソフビ風3Dに

Mimiの3D化で最終的に効いた判断を、1つの指示にまとめたものです。最初に入力した原文ではありません（原文と経過は [PROCESS.md](PROCESS.md)）。自分のキャラクターで使うときは **[置き換える]** を差し替えてください。Claude Codeなどのエージェントに、そのまま渡せる形にしています。

---

**[置き換える：キャラクター名]**（添付の2Dイラスト）を、Blender 5.2のPythonスクリプトだけで3Dモデルにする。目標は「ソフビのデザイナートイ／3Dアニメ短編のキャラクター」の見た目。以後のショート動画で何度も使い回す正本にする。

## 準備

1. 画像生成AI（Codexの画像生成など）で、元のイラストから2枚作る。
   - 三面図：同じキャラを正面・斜め前・横・後ろで横並び、白背景、直立、両目を開け、口は閉じた小さな笑顔、同じ縮尺・同じ地面の線、正投影ふう、影と文字なし。元の比率（頭身、耳の長さ、小物）を守る。
   - 仕上がり見本：同じキャラをマットなソフビ（うっすら内側から光が回る）、柔らかいスタジオ光、斜め前、明るい無地背景、9:16で。
2. 仕上がり見本を「目標」として依頼者に確認してもらう。以後の比較はすべてこれと行う。

## 作り方

- **全部スクリプトで作る**。`blender -b -P mimi.py` で一から再生成できる状態を保つ。手で直したら必ずスクリプトに戻す。
- **体は1つの塊**：頭・胴・足・手を楕円体で置いて結合し、ボクセルで再構成→スムージング。首の継ぎ目を作らない。頭は大きく、頬側を少し広げた餅形。
- **顔は表面に乗せる**：目・鼻・口は、顔へ光線を飛ばして当たった点と向きに置く。目は紺の楕円、白い光は片目に1つ（右上）。口は丸い2つの山の曲線。
- **平らな模様はシェーダーで描く**：耳の内側の色、ほっぺは、ジオメトリで貼らず、マテリアルの中で形を計算して塗り分ける（縁がなめらかで、めり込まない）。
- **小物は別部品**：ヘッドホンなど。部品同士の交差を数値で検出するスクリプトを作り、交差0を毎回確認する（耳×バンド、頭×バンド）。
- **骨組み**：root › 胴 › 頭 › 耳（左右）、胴 › 腕（左右）。体は自動ウェイト、顔と小物は頭の骨に固定。
- **質感**：白はわずかに暖かいオフホワイト、粗さ0.55〜0.6、内部散乱はごく弱く。ブランド色は彩度を落とさない（Standard表示＋露出補正）。**[置き換える：ブランド色のhex]**
- **撮影**：継ぎ目のないスタジオ背景、大きな柔らかいキー、弱いフィル、リム。背景と照明はカメラと一緒に回す（全方向の画像を同じ条件で出す）。

## 確認の回し方

1. 試しは低解像度（40〜60%）・少サンプル（24〜64）、本番だけフル品質。
2. 毎回「目標｜現在」を横に並べた画像を作る。
3. 別のAI（Codexなど）にアートディレクターとしてレビューさせる：画像とスクリプトを渡し、**差の大きい順に最大6つ、関数名と数値つき、確信度つき**、残すべき点も。出荷できるなら1行目に「SHIP」。
4. 指摘の採否は判断者が決める。依頼者の決定（例：体を細くしない）はレビューのプロンプトに書く。
5. 同じ項目で提案が2回反転したら（構図、光、手の大きさ）、値を固定し、プロンプトに「固定済み・壊れていない限り触れない」と書く。
6. 変更のたびに交差チェック → 描画 → 比較。最終はSHIP判定と依頼者の承認。

## 仕上げに出すもの

- 正本の `.blend`、生成スクリプト、交差チェック、動作テスト
- 4方向（斜め・正面・横・後ろ）の完成画像と、それをまとめたシート
- 識別の決まり（シルエット、色のhex、顔の位置、小物の向き、骨の名前）と既知の制限
