# Mimi 3D — the mascot as a soft vinyl toy

**English** · [日本語](README.ja.md)

Lanclo's 2D mascot Mimi rebuilt in Blender 5.2 entirely from Python, finished through nine review rounds between Claude Code and Codex, and approved as the 3D master for animated shorts.

![Model sheet](process/12-final-sheet.jpg)

## Files

- [PROCESS.md](PROCESS.md) (Japanese): the full making-of in order — the owner's directions, every prompt, each review round and what was accepted or rejected, with progress images.
- [PROMPT.md](PROMPT.md) (Japanese): a consolidated instruction for doing the same with another character.
- [prompts/](prompts/): the exact prompts given to Codex (original English).
- [reviews/](reviews/): Codex's reviews (rounds 3–9 and the final verdict verbatim; rounds 1–2 summarised).
- [source/](source/README.md): scripts and references as of v1.
- General guide: [docs/3D-CHARACTER-WORKFLOW.md](../../docs/3D-CHARACTER-WORKFLOW.md).
