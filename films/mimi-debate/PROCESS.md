# 制作の経緯

オーナーの言葉（承認済みの企画、親セッション経由）：

- 友だちに英語で「Dog person or cat person?」と詰められ、Mimiは言い返せない（しぼむ）。Lancloのディベートでテーマと立場を選び、意見を録音し、AIの反論・質問と言い方のフィードバックを受けて、返答する。リベンジでは自信をもって答えて、やりとりに勝つ。
- オチ（オーナー）：友だち「…てか、あんたうさぎだけどね」

判断：

- アプリは勝ち負けを決めず、意見の正しさも判定しない（`docs/features/debate.md`）。「勝ち」はリベンジのコントだけで表し、アプリの字幕では言わない。字幕はアプリの画面に合わせた：テーマと立場を選ぶ／自分の意見を録音（1回3分まで：`FreeSpeechContract.recordingSeconds = 180`）／言い方のフィードバック／AIが反論して、質問（画面の見出し「相手の意見」）／返答を録音（ボタン「返答を録音する」）。
- 現行のフィードバック画面には内容・文法などの点数の図があるが、オーナーの方針（意見は採点しないと見せる）とぶつかるので映さず、文法の直し（Money make → makes）とよかったところの部分を使った。
- アプリはシミュレーターの実画面、Lanclo `origin/main` 57b4fc93。UIテストの `--uitesting --visual-fixtures --qa-debate --qa-free-speech-v3`（英語・お金と幸せのQA用の返答：文字起こし、文法と発音の指摘、相手の意見と質問）。日本語UI。`--reset-onboarding` は使っていない。QAモードでは録音ボタンが無音の合成音声を即座に受け取るため、録音中の画面が出ない。録画用の作業コピーだけに `--qa-film-live-mic` を足し、シミュレーターのマイクで実際に録音させた（`source/app-capture/live-mic.patch`、アプリ本体は変更なし。返答はQA用データのまま、音声はどこにも送っていない）。
- 立場は「賛成」（気になる点もありますが、賛成の気持ちが上回ります）。QA用の文字起こし「…although relationships matter too」に合う。
- 「デモデータ」の表示は白で隠した。立場を選んだあとの画面送りの途中にも出るため、タップの直後で切った。
- 友だちの英語は af_bella（①から）、Mimiの英語は af_heart（会話練習の回から）。同じ質問を2回使い、リベンジの答えは「意見＋理由」に「How about you?」で聞き返す形（ディベートで練習した形）。日本語の台詞は吹き出し。英語の吹き出しには小さく日本語訳を添え、英語字幕版では英語の台詞に字幕を重ねない。
- ポーズは新しく描かず、既存のものを使った：友だち tease / oops / tsukkomi、Mimi stunned / droop / confident / sheepish（出典は source/README.md）。
- 尺は19.75秒で、目安（16〜18秒）より長い。アプリ5手順（7.6秒）とリベンジの往復（質問→即答→聞き返し→友だちが詰まる）を残したため。

学び：ディベートのQAモードは録音を合成で済ませるので、録音中の画面を撮るには録画専用のフラグでマイク録音に戻す。フィードバックの後、返答の画面（2/2）に「相手の意見」がまとまって出るので、反論の説明にはそこを使うとよい。
