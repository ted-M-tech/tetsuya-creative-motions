# 17言語、ぜんぶ自分の声（AIボイスの言語切り替え）

[English](README.md) · **日本語**

最初の1秒で、友だちが Hello! Bonjour ! ¡Hola! 你好！ 안녕하세요! Ciao! Olá! नमस्ते! …と次々あいさつ（実際の声の長さに合わせて切れ目なく、全部同じ一人の声）→ コピー「17言語、ぜんぶ自分の声。」（アプリの17の学習言語が流れる）→ Mimi「声の登録は一度。あとは言語を変えるだけ！」→ 実アプリ（シミュレーター、テスト用データ）：AIボイス画面の 🌐 言語メニュー → Français → 読み込み中… → 「将来の発音」がフランス語に、試聴 → 한국어 で韓国語の文 → 友だち「来月の韓国旅行、これで練習しよ！」→ エンドカード。19.55秒、1080×1920、60fps。日本語のみ版と英語字幕版の2本。

**音声はオーナー本人がLancloに登録した声のAIボイス**（Gemini gemini-3.8-flash-tts）。英・仏・西・中・韓・伊・葡・印のあいさつとアプリのフランス語の文を、すべて同じ一人の声で、その言語のネイティブの発音で（`source/own-voice.json`）。最後に一気に出るドイツ語・ロシア語・トルコ語・ベトナム語・日本語は吹き出しのみ。声のファイルは生体情報なのでGitに入れず Drive `Multilang_assets/own-voice/` に保管。画面の注記は「※音声は制作者本人がLancloに登録した声のAIボイスです」。画面の友だちは女の子だが声はオーナー（男性）の声。
