# 17言語、ぜんぶ自分の声（AIボイスの言語切り替え）

[English](README.md) · **日本語**

最初の1秒で、友だちが Hello! Bonjour ! ¡Hola! 你好！ 안녕하세요! Ciao! Olá! नमस्ते! …と約0.33秒ごとに次々あいさつ（全部「わたしのAIボイス」）→ コピー「17言語、ぜんぶ自分の声。」（アプリの17の学習言語が流れる）→ Mimi「声の登録は一度。あとは言語を変えるだけ！」→ 実アプリ（シミュレーター、テスト用データ）：AIボイス画面の 🌐 言語メニュー → Français → 読み込み中… → 「将来の発音」がフランス語に、試聴 → 한국어 で韓国語の文 → 友だち「来月の韓国旅行、これで練習しよ！」→ エンドカード。18.7秒、1080×1920、60fps。日本語のみ版と英語字幕版の2本。

**音声は合成音声（Kokoro）の代用で、声のクローンではない。** 言語ごとに Kokoro の女性の声を1つずつ（あるものだけ）。韓国語・ドイツ語・ロシア語・トルコ語・ベトナム語・日本語は吹き出しのみ。画面にも「※動画の音声は合成音声によるイメージです」と表示。
