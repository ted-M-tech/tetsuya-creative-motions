# 制作の経緯

オーナーの言葉：

- 「5.フック弱い。1秒で自分の同じ言語の多言語が流れてくる。」（＝最初の1秒で、同じ人の声のまま、いろいろな言語が次々流れてくる）

親セッションからの筋：フック（English / 한국어 / Français / Español / 中文 / Deutsch…の吹き出し・波形を約0.3秒ずつ、全部「自分の声」）→ コピー「17言語、ぜんぶ自分の声。」→ 実アプリで学習言語を切り替え、お手本が自分の声でその言語で流れる → 友だちの反応（韓国旅行／K-POP）→ エンドカード。

判断：

- 確認したこと（主張を超えないため）：アプリの学習言語は17（`packages/core/src/studyLanguages.ts`：en, ja, zh, ko, fr, es, th, yue, de, it, pt-BR, id, vi, hi, bn, ru, tr）。AIボイス画面の言語メニューは同じ17言語で、切り替えると `prepareVoiceAudition` がその言語で自分の声の試聴を作る（なければ生成）。各言語の試聴の文はアプリ同梱（`voice-readings.json` の auditions）。LP（`docs/self-voice-practice/lp-multilingual.md`）の承認済みコピーは「あなたの声で、17言語のお手本を。」「声の登録は一度。あとは、言語を変えるだけ。」で、Mimiの台詞はこれに合わせた。発音が身につくとは言わない。
- フック：同じ一人（友だち）が言語を次々話す絵にした。あいさつ1語なら0.33秒で聞き取れる。最初の1秒に英・仏・西の3言語。
- 声：本物のクローンは使えないので Kokoro の合成音声で代用。言語ごとに Kokoro の女性の声を1つ（英語は①以来の友だちの声 af_bella）。英語の声に他言語を読ませると同じ声色にはなるが発音が英語なまりになるため、ネイティブの発音という約束を優先して各言語の声にした（声色は言語ごとに違う＝クローンではない点は CREDITS と画面の注記に明記）。Kokoro に声のない韓国語・ドイツ語・ロシア語・トルコ語・ベトナム語と、崩れる日本語は吹き出しとポップ音のみ。
- アプリ：シミュレーターの実画面（Lancloの `origin/main` 57b4fc93）。`--uitesting --visual-fixtures --qa-route /voice` でAIボイス画面（将来の発音）が開くが、テスト用データには音声の提供元がないため、言語を切り替えると「声を利用できません」になる。録画用の作業コピーだけに `--qa-film-voice-stub` を足し、言語切り替えに0.9秒待って4秒の無音WAVを返すようにした（`source/app-capture/voice-stub.patch`、アプリ本体は変更なし）。画面の動き（読み込み中→文がその言語に→試聴の再生バー）は本物、音は動画側でのせた。
- 中文（普通话）も撮ったが、名前が長くてツールバーのメニューが「…」に畳まれてしまうので外し、フランス語と韓国語にした。韓国語は Kokoro に声がないので、文が韓国語に変わるところまで見せて友だちの反応へ。
- 新しいポーズ2枚（友だち：あいさつ／韓国旅行のガイドブック）は codex-p で公式アートと友だちの既存ポーズから作画（`prompts/01-codex-poses.txt`）。

- 2026-10-21 オーナーの指示「今まで英語で発音シーンがあった動画、この声で変えて。010以外。」で、Kokoro の言語ごとの声をすべてオーナー本人がLancloに登録した声（Gemini gemini-3.8-flash-tts、`kits/mimi-short/scripts/ownvoice.py` の `native` + `language`）に差し替え。デバイス録音を頼む案はやめた。メッセージが「同じ声（自分の声）で全言語」なので、英・仏・西・中・韓（新たに声あり）・伊・葡・印のあいさつとアプリのフランス語の文を同じ一人の声に。あいさつは silencedetect で測った発声区間だけを1.15倍（音程そのまま）で切れ目なく並べ、吹き出しを各語の出だしに合わせた（全体で0.85秒伸びて19.55秒）。フランス語の文は 9.22–11.99秒、韓国語の文は試聴を押していないので音なしのまま。whisper で各言語の聞き取りを確認（英 Hello / 仏 Bonjour / 西 Hola / 中 你好 / 韓 안녕하세요 / 伊 Ciao / 葡 Olá / 印 नमस्ते、仏の文も全文一致）。画面の友だちは女の子だが声はオーナー（男性）。注記は「※音声は制作者本人がLancloに登録した声のAIボイスです」。

学び：AIボイス画面の言語切り替えはテスト用データでは失敗するので、録画には無音を返すスタブが要る。ツールバーのメニューは長い言語名で畳まれる。
