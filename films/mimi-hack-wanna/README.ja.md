# 発音のコツ 3 - Wanna and Gonna

[English](README.md)

Lanclo SNSショート #074。シリーズ「Pronunciation Hacks（発音のコツ）」第3話。ドラフト（2026-10-23、オーナー確認待ち）。16.9秒、1080×1920、60fps、2本（日本語のみ／英語字幕つき）。第1話 [mimi-hack-check-it-out](../mimi-hack-check-it-out/README.ja.md) のテンプレートから作成。

コツ：**くだけた会話**では want to → **wanna**、going to → **gonna**（to がとけて na になる）。カードに小さく注意：会話だけ、文章では want to。

カフェ。1フレーム目から「ネイティブ、toを言ってない？」、ミミが速く「I wanna go. I'm gonna try.」（オーナーの声）。もう一度言うが友だちは聞き取れない（「I ？？？ go. / I'm ？？？ try.」「速すぎて…」「聞き取れない…」）。スロー解説カード：ゆっくり「Want to.」→ふつう「Wanna.」、ゆっくり「Going to.」→「Gonna.」。カフェに戻ってもう一度聞くと友だちが聞き取れて「I'm gonna try!」、ハイタッチ。「次のコツは？」のあとエンドカード。

| 秒 | ビート | 内容 |
|---|---|---|
| 0.00–2.00 | `hook` | 「ネイティブ、toを言ってない？」、0.15秒に速いセリフ |
| 2.00–4.50 | `slip` | もう一度。wanna / gonna の所は赤い「？？？」、「速すぎて…」「聞き取れない…」 |
| 4.50–7.00 | `tip` | カード：want to（ゆっくり、to に取り消し線）→ wanna |
| 7.00–9.70 | `model` | going to → gonna、「くだけた会話だけ 文章では want to」 |
| 9.70–13.50 | `fix` | 「もう一回 聞くと…」→ 友だち「I'm gonna try!」、「聞き取れた → 言えた！」、ハイタッチ |
| 13.50–15.30 | `cta` | 「次のコツは？」「知りたい発音、コメントで！」 |
| 15.30–16.90 | `end` | エンドカード、15.9秒でCTAタップ |
