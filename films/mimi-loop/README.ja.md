# ひとつのループ（Lanclo）

[English](README.md) · **日本語**

友だちが架空のAIチャットで英語を勉強中。「"touch base" ってどういう意味？」と打つと、長い説明が流れていく。スマホの後ろには、ほかの勉強アプリ（AI会話・単語カード・コピペメモ・発音動画。ブランドなし）が積み重なる。Mimiの司会で「AI英語学習の悩み TOP7（Mimi調べ）」（「※Mimiの独断です」）を7位から発表し、1位は「聞いたら終わりで、すぐ忘れる」。友だちは「わかる…」。Mimi「Lancloなら、勝手に回るよ」→ コピー「続けられて、変化が見える。」→ アクションボタンひと押しでLancloが開く（6位）→ 真ん中にLancloの実画面（シミュレーター）がある7つの止まり場所のループ。Mimiが走って回り、止まるたびに実画面を見せ、ランキングの悩みに✓をつける：①お手本は自分の声（5位）②5つの観点のスコア（2位）③話した英語をMimiが添削（3位）④いい言い方はワンタップで保存（4位）⑤Mimiが決めるデイリーレッスン ⑥学習記録（7位）⑦忘れかけたころにまた出てくるスワイプ復習（1位）。速くなる周回でスコアが上がる（「※数値はイメージ」）。友だち「自然に続けられて、変化が見れる…これが大事なんだよね」。1週間後、夜のベッドで復習カードをスワイプし続けて「やば…Lanclo沼から抜けられない…」。Mimi「それ、続いてるってことだよ」。エンドカード。
