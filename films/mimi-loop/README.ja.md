# ひとつのループ（Lanclo）

[English](README.md) · **日本語**

友だちが架空のAIチャットで英語を勉強中。「"touch base"ってどういう意味…？」と聞くと長い説明があふれ、スマホの後ろにはほかの勉強アプリ（AI会話・単語カード・コピペメモ・発音動画。ブランドなし）が積み重なっている。履歴には同じ質問が3回。「昨日も同じこと聞いてる…」。Mimiの司会で「AI英語学習の悩み TOP7（Mimi調べ）」（「※Mimiの独断です」）を7位から発表し、1位は「聞いたら終わりで、すぐ忘れる」。友だちは「わかる…」。Mimi「Lancloなら、全部まとめて回るよ」→ コピー「続けられて、変化が見える。」→ 真ん中にLancloの実画面（シミュレーター）があるループ。止まり場所は7つで各1.7秒。Mimiが走って回り、実画面を見せながら、解決するランキングの悩みに✓をつける：①お手本は自分の声（6位）②5つの観点のスコア（4位）③話した英語をMimiが添削（3位）④Mimiのアドバイス ⑤アクションボタンひと押しで今日のレッスン（2位）⑥学習記録（5位）⑦ワンタップで保存、忘れかけたころにまた出てくる復習（7位・1位）。速い周回でスコアが上がる（「※数値はイメージ」）。友だち「自然に続けられて、変化が見れる…これが大事なんだよね」。1週間後、夜のベッドで復習カードをスワイプし続けて「やば…Lanclo沼から抜けられない…」。Mimi「それ、続いてるってことだよ」。エンドカード。
