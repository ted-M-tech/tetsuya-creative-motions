# ひとつのループ（Lanclo）

[English](README.md) · **日本語**

友だちのスマホには勉強アプリが5つ（意味調べAI・コピペメモ・AI会話・発音動画・単語カード。どれも架空で、ブランド名・ロゴなし）。どれも途中で止まって、ほこりをかぶる。「勉強が続かない…」。Mimi「それ、全部ひとつで回るよ」。コピー「バラバラの勉強を、ひとつのループに。」。続いて、真ん中にLancloの実画面（シミュレーター）、まわりに7つの止まり場所があるループ。Mimiが走って回り、止まるたびに実画面を2〜3秒：①発音練習（お手本は自分の声）②苦手分析（音・単語の強勢・リズム・抑揚・流暢さ）③シチュエーション会話と英語日記 ④Mimiのアドバイス（あなたの癖、「ネイティブなら」）⑤Mimiが気づいた癖で組んだデイリーレッスン ⑥学習記録（発音のバランスと推移）⑦スワイプ復習。2周目・3周目は速くなり、スコアが上がる（「※数値はイメージ」と明記）。友だち「…ずっと回せるやつじゃん」。エンドカード。
