# ひとつのループ（Lanclo）

[English](README.md) · **日本語**

友だちが架空のAIチャットで英語を勉強中。「"touch base"ってどういう意味…？」と聞くと長い説明があふれ、スマホの後ろにはほかの勉強アプリ（AI会話・単語カード・コピペメモ・発音動画。ブランドなし）が積み重なっている。履歴には同じ質問が3回。「昨日も同じこと聞いてる…」。Mimiの司会で「AI英語学習の悩み TOP7（Mimi調べ）」（「※Mimiの独断です」）を7位から1秒ずつ発表し、1位は「聞いたら終わりで、すぐ忘れる」。友だちは「わかる…」。Mimi「Lancloなら、全部まとめて回るよ」→ コピー「続けられて、変化が見える。」→ 7つの悩みがLancloを囲むループへ飛んでいき、それを解決する止まり場所に1つずつ着地する。Mimiが学習の順に1周（1つ1.25秒）。止まるたびに実画面が映り、悩みに線が引かれ、カードが裏返ってLancloの答えになる：入口（アクションボタン・デイリーレッスンのウィジェット）、あなた専用のレッスン、自分の声のお手本、Mimiのアドバイス、しおりで保存、スワイプ復習、学習記録。続いて「→ 次のレッスンに反映」と、速い1周でスコアが上がる（「※数値はイメージ」）。友だち「自然に続けられて、変化が見れる…これが大事なんだよね」。1週間後、夜のベッドで復習カードをスワイプし続けて「やば…Lanclo沼から抜けられない…」。Mimi「それ、続いてるってことだよ」。エンドカード。
