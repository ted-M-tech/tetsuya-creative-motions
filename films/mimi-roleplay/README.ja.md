# ロールプレイ — カフェで固まる

[English](README.md) · **日本語**

カフェのカウンターで、エプロン姿の友だちに "For here, or to go?" と聞かれてMimiがカチッと固まる。Lanclo の会話練習でカフェの場面を選び、AIの会話相手とやりとりし、「ヒントがほしい？」で答え方を確認して録音、シチュエーション完了。本番ではスラスラ注文できたのに、"Would you like it hot, or iced?" でまた固まる——今度は笑って氷を割り、ほかの場面へ。コピー「いろんな場面で、何度でも。」。アクションボタンとは切り離した単体の1本。
