# たこ先生 — 動く関西弁。

[完成作品](https://maepace.com/works/tako-stickers)

承認済みLINEスタンプを、音がなくても伝わる一枚のポスターに。中央のタイトルに余白を残し、周囲のリアクションを同時に動かしています。

Approved LINE stickers become a sound-off living poster. A clear central title leaves room for simultaneous reactions around it.
