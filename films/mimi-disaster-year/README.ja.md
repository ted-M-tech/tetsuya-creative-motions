# Pronunciation Disasters 15 - Year / Ear

[English](README.md)

Lanclo SNS ショート #057（シリーズ「Pronunciation Disasters / 発音で大事故」第15話）。ドラフト。18.8秒、1080×1920、60fps、2カット（日本語のみ／英語字幕つき）。12月下旬に投稿予定。

場面：雪の神社の元日の朝。友だちがMimiに「Happy New Year!」と手を振るが、カタカナの「イヤー」で y が抜けて “Happy New Ear!” に。空気が凍り、Mimiがうやうやしくピンクの耳あてを差し出す（「新しい耳です。」）。そしてMimiが飛び出して「それ「新しい耳」に聞こえてる〜！！」。キャストはMimiと友だちの二人だけ。

構成はシリーズ共通：1フレーム目にオチ（「Happy New 耳（耳アイコン）？」）→ 巻き戻し → 状況フック → 言い間違い → フリーズ → Mimi → 自分の声の2テイク比較カード（year＝舌を上あごへ「ィ」から／ear＝「ィ」なしの「イヤー」）→ 実際のLanclo画面 → 言い直し → エンドカード＋CTAタップ。
