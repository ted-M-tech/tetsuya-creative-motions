# 単語帳のデータ、全部Mimiに食べさせた（CSVの作り方）

[English](README.md) · **日本語**

[mimi-import](../mimi-import/README.ja.md)（#20 Mimi Eats Your Files）の続編。1コマ目から単語カードがMimiの口に飛び込み、フック「単語帳アプリのデータ、全部Mimiに食べさせた」。CSVの作り方を、アプリ名・ロゴなしのイメージで：①単語帳アプリからCSVで書き出し ②表計算で開いて1行目を term / meaning に（C列 tags はフォルダ名、なくてもOK）③CSV（UTF-8）で保存 →「単語帳.csv」。実アプリ（シミュレーター、テスト用データ）：マイノート「CSVファイルを選ぶ」→ Mimiがファイルを食べる「いただきまーす！」→ 新しく追加できるノート 10件 → 10件を追加しました。→ マイノートに「単語帳」10件 → 復習カード「look forward to」（オーナー本人の登録した声のお手本）。友だち「いつもの単語帳が自分の声のお手本に！」、Mimi「ごちそうさま〜♪」→ エンドカード。21.1秒、1080×1920、60fps。日本語のみ版と英語字幕版の2本。
