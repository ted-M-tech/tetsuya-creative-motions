# 制作の経緯

オーナーの言葉：

> 「スマホだけなく、タブレットでもパソコンでも、ってことを言う動画をつくりたい。LancloはWeb版もある。スマホだと、すぐYouTubeとか見て、勉強やめてしまう・・・パソコンとかタブレットでやりたいな。パソコンからMimiが登場！しかもデータも同期されているから、家ではパソコン、電車ではスマホとか、好きなようにできる。ずっと友達がAndroidの自分は・・・？と聞いてきて、近いうちに対応するで！それまではWeb版で使ってね！って案内する」

親セッションからの指示（要約）：動画アプリは実名・ロゴなし（汎用の赤い再生アイコン）、Androidは予定でありMimiの約束として、日付なし、同期は確認できたことだけ、18〜22秒。

判断：

- 実在サービス名は出さない。通知は「動画アプリ／おすすめ：ネコの爆笑まとめ」、動画画面もCSSで描いた汎用のもの。
- Web版の画面は本物。Lancloリポジトリ（main 57b4fc93）を書き出し、Node 24でローカルの開発サーバーを起動。ホームはリポジトリのテスト用フィクスチャ `voice-web/tests/daily-home-fixture.tsx` の `habits` 状態（`daily-home-browser.ts` と同じ手順。APIはすべてフィクスチャ、GETのみ）、練習の一覧はゲスト＋APIモック（`web-parity-shell-browser.ts` と同じ）。撮影スクリプトは `source/web-capture/`。本番サイトへのログインやフォーム操作はしていない。
- 表示するURLはリポジトリの `WEB_APP_URL='https://lanclo.app/'`（`voice-web/src/landing/iosLaunch.ts`）。
- 同期の主張は `docs/architecture/account-sync.md`（同じアカウントでiOSとWebが同じデータ：練習履歴、単語帳、設定など、アカウント保存がオンのとき）と、iOSの文言「練習履歴・単語帳・設定をこのアカウントで同期します。」に合わせ、「同じアカウントでログインすれば 練習履歴も単語帳も同期！」とした。
- 「同じ進み具合」の見せ方：WebのホームのフィクスチャはMimiレポートのフィクスチャと同じ日記データ（「And then」4回、「good」3回）。iOSのMimiのアドバイス（「ひとつのループ」の録画、Drive `018/Loop_assets/`）も同じ数字なので、両方の「And then 4回」の行をハイライトしてつないだ。ストリークや練習カレンダーは両フィクスチャで数字が違うため、同期の場面では使っていない。
- 冒頭の勉強中のスマホは同じ録画の会話練習（シチュエーション）の1コマ。「デモデータ」の表記は背景色で塗りつぶした（`source/scripts/screens.sh`）。
- Androidの友だちは、friend案出しのときのロップイヤー案（`films/mimi-action-add/source/art/friend/b-lop.png`）を2人目として採用。ミントグリーンのスマホ（ロゴやロボットなし）。最初の下書きはヘッドホンなし（まだLancloを使えない、という意図）。3回の「…Androidの私は？」：デバイス紹介、同期、締め。
- Mimiの返事は関西弁のオーナー原文のまま：「近いうちに対応するで！」「それまではWeb版で使ってね！」。日付は出さない。
- 新しいポーズ6枚（友だち：笑う／机でパソコン／電車でつり革、ロップイヤー：聞く／むくれる／大喜び）は codex-p で作画（`prompts/`）。Mimiはライブラリの jump と confident、友だちの type・sigh・wow は「ひとつのループ」から。

オーナーの確認（下書き1のあと）：

> 「この子にヘッドホンつけて」

→ ロップイヤーの3ポーズ（聞く／むくれる／大喜び）を、Mimiと友だちと同じヘッドホン（紺のバンド、青いカップ、見る人から見て左のカップに白い「L」）をつけて codex-p で描き直した（`prompts/03-codex-lop-headphones.txt`、元のポーズと公式アートを参照）。バンドは頭の上、カップは垂れ耳の付け根の前に置き、耳は下へ自然に垂らす。ほかの演出・タイミングは変えていない。

学び：Web版の開発サーバーは `voice-web` だけでなくリポジトリ直下の依存（`ts-fsrs`）と `design/mimi-2d` が必要。Webホームの `habits` フィクスチャとiOSのMimiレポートのフィクスチャは同じ日記データなので、端末をまたいだ同じ表示を本物の画面で見せられる。
