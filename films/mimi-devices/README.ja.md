# スマホでも、タブレットでも、パソコンでも

[English](README.md) · **日本語**

スマホで勉強しようとした友だちが、動画アプリの通知で脱線（「あはは！」）→「スマホだと、すぐ動画見ちゃう…」「パソコンかタブレットでやりたいな」→ Mimiがノートパソコンの画面から飛び出して「LancloはWeb版もあるで！」→ 実際のWeb版（lanclo.app）をパソコンとタブレットで → 家ではパソコン、電車ではスマホ：同じ「And then」の癖が両方に出て「同期」でつながる（「同じアカウントでログインすれば 練習履歴も単語帳も同期！」）→ コピー「スマホでも、タブレットでも、パソコンでも。」→ 3回「…Androidの私は？」と聞いてくるロップイヤーの友だち（同じヘッドホン）に、Mimi「近いうちに対応するで！」「それまではWeb版で使ってね！」→ エンドカード。20.0秒、1080×1920、60fps。日本語のみ版と英語字幕版の2本。
