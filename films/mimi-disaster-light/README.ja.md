# Pronunciation Disasters 11 - Light / Right

[English](README.md)

Lanclo SNS ショート #052（シリーズ「Pronunciation Disasters / 発音で大事故」第11話）。19.75秒、1080×1920、60fps、2カット（日本語のみ／英語字幕つき）。

場面：ホストファミリー（クマのブルーノ）の家で部屋が真っ暗。友だちが「Could you turn on the light?」と頼むと「turn on the right」に聞こえ、ブルーノは右向きの矢印標識を持って何度も右を向く。まだ真っ暗。懐中電灯を持ったミミが「それ「right」（右）に聞こえてる〜！！」。正しく言い直すと電気がつく。

構成はシリーズの型（[mimi-disaster-sit](../mimi-disaster-sit/)）、近いのは第3話 [mimi-disaster-rice](../mimi-disaster-rice/)（同じ L/R、今回は L が正解）。

- 声：学習者テイクとお手本はオーナーの登録済みLanclo音声（ownvoice.py）。WAVはGitに入れず Drive `052. Pronunciation Disasters 11 - Light or Right/Disasters11_Light_assets/own-voice/`。ブルーノはKokoro英語。
- 口の図（r / l）は第3話から再利用。L＝舌先を上の歯の裏（歯ぐき）につける、R＝舌はどこにもつけず唇を少し丸める。
- ミミの一人称は「僕」（本作のミミのセリフには一人称なし）。
