# カタカナの罠 2 - マンション

[English](README.md)

Lanclo SNSショート #059。「カタカナの罠」第2話（意味の罠：発音は正しいのに、意味が違う）。完成版（2026-10-23、オーナー承認済み）。15.1秒、1080×1920、60fps、2本（日本語のみ／英語字幕つき）。

街角でミミと友だちがおしゃべり。1フレーム目から「マンション住み＝豪邸持ち？」と、噴水つきのお城を思い浮かべるミミの吹き出し。友だち（オーナー自身の声）「I live in a mansion.」→ ミミの吹き出し（字幕のみ）「Wow, you're rich!」でお城がふくらみ、友だちがあわてる。ミミのカード：英語の mansion＝大豪邸／日本のマンションは apartment（米）・flat（英）・condo（分譲）、お手本「I live in an apartment.」を自分の声で2回。続けて早押しカード：コンセント→outlet、クレーム→complaint（それぞれ自分の声）。「他の和製英語トラップ、コメントで！」の間にお城の吹き出しがしぼみ、エンドカード。
