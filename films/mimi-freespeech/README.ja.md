# 3分、話しつづけて — 2D Mimiショート

[English](README.md) · **日本語**

絶望するMimi「こんなの学校でやったことなかったもん！」（今まで、こんな練習したことあった？）。Lancloの写真描写：写真を見て自分の言葉で話す（アプリ表示「最大 3:00」）。Mimiは台本なしで話しつづけ（時計は早送りで3:00まで）、AIの5つの観点のフィードバックと話した内容の文字起こしを見る。フランス人の友だち（ベレー帽・ボーダー・バゲット）は「3分じゃ短いから、もっと録音伸ばせない？」。Mimi「…こっちは3分が長いんだけど」。メッセージ「“使える”英語は、自分で考えて話すことで伸びる。」（参考：Swain (1985) アウトプット仮説）

0:18.6 / 1080×1920・60fps / 日本語の吹き出しと字幕、Mimiの英語と友だちのフランス語はKokoro TTS / 公式2Dポーズ＋GSAP、実アプリ（シミュレーター）＋HyperFrames

2本：日本語のみ（`mimi-freespeech.mp4`）と英語字幕つき（`mimi-freespeech-en.mp4`）。下書きはLancloのGoogleドライブ `002.SNS/021. Keep Talking for 3 Minutes/`（録画と切り出しは `FreeSpeech_assets/`）。
