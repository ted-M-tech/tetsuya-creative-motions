# 4,280円 — 言える？標準語のアクセント。

提供された会話を切り詰めず、言い直しや間も含めて演出。発話に合わせて日英字幕と話者の表情を切り替え、最後に短い導線を添えました。

## 再制作の流れ

1. 音声を先に確定し、発話単位のタイムコードを採る。
2. 話者ごとに吹き出しとキャラクターを対応させる。
3. 会話の間を残し、BGMを足さず声を主役にする。
4. 音声の実測時間に字幕と動きを合わせる。別の題材で作る場合は、台本・声・キャラクターを自分が利用できるものに置き換える。
5. 9:16の画面で文字の欠け、字幕の先走り、音声の途切れを確認する。

## 記録の範囲

完成物からの再構成を含みます。元の全会話ログや完全な制作環境の公開ではありません。
