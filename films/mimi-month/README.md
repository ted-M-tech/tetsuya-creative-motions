# Watched by Mimi for a Month — a 2D Mimi short

**English** · [日本語](README.ja.md)

Hook from the first frame:「Mimiに1ヶ月見張られた結果」(What happened after Mimi watched me for a month): Mimi zooms in with binoculars, the friend shivers and a day counter races from 1 to 30. Then an upbeat time-lapse of Mimi's daily report in the real app, recorded with example data for five days: day 1, the first report (「最初のレポートだよ」, today's practice points); day 7, "And then" 4 times; day 14, "And then" is gone and "I think" shows up; day 21, now "very"; day 30, 「いい調子！この7日間は目立つ癖はなかったよ。」— Mimi droops ("…nothing left to watch"), the friend cheers. Copy:「アドバイスも、あなたと一緒に育つ。」 The example data is labelled on screen.

0:18.6 / 1080×1920, 60 fps / Japanese captions and bubbles, no voices / official 2D poses + GSAP, real app (simulator, QA fixtures + a capture-only day patch) + HyperFrames

Two cuts: Japanese only (`mimi-month.mp4`) and with English subtitles (`mimi-month-en.mp4`); final files in Lanclo's Google Drive `002.SNS/036. Watched by Mimi for a Month/` (`Month_2026-10-21.mp4`, `Month_EN-subs_2026-10-21.mp4`, raw take in `Month_assets/`).
