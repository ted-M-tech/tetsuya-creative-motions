# 声の調整（アクセントもリクエスト）

[English](README.md) · **日本語**

[mimi-voice](../mimi-voice/README.ja.md) の続編。Mimiが自分のAIボイスを聞いて首をかしげる「なんか、ちょっと私っぽくない…？」→ コピー「AIボイスは アクセントも リクエストできる！」→ 実アプリ（シミュレーター、テスト用データ）の「声の調整」：話し方（落ち着いて／ゆっくり／穏やか）→「発音・話し方のリクエスト」に「イギリス英語っぽく」→「試聴音声を作る」→「すべてのボイス」で聴きくらべ → イギリス風の試聴音声（合成音声のイメージ）→ 山高帽とティーカップのMimi「……イギリス帰りの私」、友だち「行ったことないでしょ！」→ エンドカード。17.4秒、1080×1920、60fps。日本語のみ版と英語字幕版の2本。
