# 統合プロンプト（完成形から逆算した指示。最初の入力の原文ではない）

Lancloの復習カード（マッチングアプリのように右・左・上へスワイプ）を紹介するMimiショートを作る。18秒以内、1080×1920・60fps、声なし（吹き出しと字幕）。

1. 0–0.9秒：フック。Mimiが真ん中でスマホを見てにやけ、画面からカード（✓・↺）が右・左・右へ飛ぶ。
2. 0.9–3.9秒：友だちが左から入り「え、それ マッチングアプリじゃん！」（指さしてニヤニヤ）。2.3秒、Mimiが慌てて「ちがうって！ これ、英語のフレーズ復習なの！」。
3. 3.9–5.0秒：白い画面にコピー1行「英語の復習も、スワイプで。」、下に「← もう一度」「↑ 簡単」「覚えていた →」のラベル。
4. 5.0–12.9秒：実際のアプリ。シミュレーターでフィクスチャのノートを開き、カードをゆっくりドラッグして離す（右・左・右・上）。1.25倍速、カードが同じところでつなぐ。左にアプリと同じ文言と色のチップ（覚えていた→／←もう一度／↑簡単）、上に字幕（覚えてたら、右。／忘れてたら、左。／1枚ずつ、サクサク。（約1秒、2倍速）／簡単なら、上。）。Mimiは横でスマホを持って揺れる。
4b. 11.95–14.25秒：なぜまた出てくるか。白いカードに「忘れかけたころに、また出てくる。」、小さく「覚えてたら間隔がのびる・忘れたらすぐもう一度」。忘却曲線（イメージのタグ）：紺の線が下がり、「忘れる」の点線の手前で青い点が出て線が戻り、次の下がり方はゆるやかに、点の間隔が広がる。ラベルはアプリのボタンにある時間だけ（1分後 → 10分後 → … → ≈8日後）。FSRSの中身や他の数字は書かない。
5. 14.25–16.85秒：オチ。Mimi（リボン・ハート）「じゃあ、マッチングアプリの人とデートしてくる！」、友だちが手の甲でツッコミ「そっちもやってるんかい！」、Mimiは右へ退場。
6. 16.1秒〜：エンドカード、CTAのタップに「ぽちっ」。BGMはLancloのSNSテーマ、SFXは小さめ。

アプリにない機能は言わない（右＝覚えていた、左＝もう一度、上＝簡単。ボタンも同じ3つ）。友だちは前作（アクションボタン①）と同じキャラ。

書き出しは2本：日本語のみと、下に英語字幕つき（日本語の文字ごとに自然な英語を1行）。
