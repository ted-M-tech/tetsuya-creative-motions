# スワイプ復習（マッチングアプリじゃん！）

[English](README.md) · **日本語**

スマホでカードを右へ左へスワイプしているMimi。友だちが「え、それマッチングアプリじゃん！」。Mimi「ちがうって！これ、英語のフレーズ復習なの！」。白い画面に「英語の復習も、スワイプで。」、続いてLancloの復習カードの実画面（シミュレーター）：右＝覚えていた、左＝もう一度、上＝簡単。「もう一度」のカードはまた出てくる。最後はMimi「じゃあ、マッチングアプリの人とデートしてくる！」、友だち「そっちもやってるんかい！」。エンドカードでCTAをタップ。
