# カタカナの罠 3 - ホテル・ギター・シャンプー

[English](README.md)

Lanclo SNSショート #060。シリーズ「カタカナの罠」第3話（アクセント回）。**ドラフト**（2026-10-23）。16.2秒、1080×1920、60fps、2本（日本語のみ／英語字幕つき）。

1フレーム目から「ホテル、強いのはどこ？」と3つの単語チップ（ホテル／ギター／シャンプー）。ホテルのロビーで友だちが日本語式（頭高）に3語を言い（オーナーの声・学習者スタイル）、各チップの最初の点が大きく赤く光る。ミミは首をかしげる。カードで単語ごとに カタカナ（1つめが大）→ 英語（2つめが大）：ho-TEL、gui-TAR、sham-POO。お手本はオーナー自身の声で、ミミが強い拍でリズムを取る。「2つめを 強く・長く・高く」。ロビーに戻り友だちが3語とも正しく言える。視聴者チャレンジ「Japanese は？」を1秒、答えは ja-pa-NESE（単語だけで言うとき。名詞の前では JApanese FOOD のように前へ、と小さく注記）。「次に通じないカタカナは？」のあとエンドカード。

| 秒 | ビート | 内容 |
|---|---|---|
| 0.00–1.20 | `hook` | 「ホテル、強いのはどこ？」、チップ3つ |
| 1.20–4.05 | `slip` | 友だち「ホテル／ギター／シャンプー」（頭高）、実測の拍で点灯、ミミが首かしげ、「カタカナは頭が強い」 |
| 4.05–7.55 | `explain` | カード3行、お手本3語、「2つめを 強く・長く・高く」、お手本＝自分の声 |
| 7.55–9.75 | `model` | 友だちが正しく3語、「2つめを強く → 通じる！」 |
| 9.75–10.75 | `challenge` | 「Japanese は？」1秒タイマー |
| 10.75–12.75 | `reveal` | ja-pa-NESE（3つめ）＋注記 |
| 12.75–14.75 | `cta` | 「次に通じないカタカナは？」「コメントで教えてね」 |
| 14.75–16.20 | `end` | エンドカード、15.35秒でCTAタップ |
