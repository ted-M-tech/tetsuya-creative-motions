# 統合プロンプト（完成形から逆算した指示。最初の入力の原文ではない）

Lanclo の新シリーズ「How Do You Say It?」第1話を、Mimi ショート（2D 公式絵柄・縦 1080×1920・60fps・約18秒）で作る。テーマは「1対1の英語がない日本語」を、iOS の実アプリのフレーズ作成（フレーズを追加 → 日本語のまま入力 → フレーズを作成 → 編集できる結果 → 保存）に入れること。キャストは Mimi と友だちの2人だけ（同僚役は Mimi の役衣装）。

1. 0–1.5秒：1フレーム目からフック「よろしくお願いします、英語で？」。オフィスで初出勤の友だちがお辞儀のまま固まり、同僚役の Mimi（水色カーディガン＋社員証）が握手の手を出している。
2. 1.5–3.95秒：友だち（オーナーの声・学習者）"Please... yoroshiku?"（間は詰める）。
3. 3.95–5.0秒：Mimi 困惑「？」、字幕「「よろしく」は直訳できない…」。
4. 5.0–11.35秒：実アプリ（シミュレーター、QA フィクスチャ）。「新しい職場でよろしくお願いします」を入力 → フレーズを作成 → 結果 → 保存。字幕「日本語のまま打てばOK」「自然な英語に。直してもOK」「保存は自分で」。結果は Lanclo の本物の作成 API がこの入力に返した答え（撮影専用パッチで表示）を大きなラベルでも見せる。
5. 11.35–15.55秒：Mimi の場面カード「よろしくお願いします」→ 初対面 "Nice to meet you." / 一緒に働く "I look forward to working with you."（どちらもオーナーの声・US）。
6. 15.55–17.35秒：オフィスに戻り、友だちが笑顔で "I look forward to working with you!"。字幕（コメント誘導）「次は何を英語にしたい？」。
7. 17.35秒〜：エンドカード、CTA タップ「ぽちっ」。BGM はテーマ「Everyone Get Up」を声の下に。

正直さのルール：画面のアプリの答えは、その入力に対して Lanclo の作成機能が本当に返すもの。AI の答えは毎回少し変わるので、取得した候補をすべて PROCESS.md に記録する。
