# 制作過程

## 依頼（原文）

オーナー：「同じような発音でとんでもない勘違いシリーズも作って。Shit、sitとか。よくある系でウケる、フック強烈に」
後続：beach/b*tch, rice/lice, election/erection, coke/c*ck, peace/p*ss。今回はパイロット（037）のみ、型は使い回せるように。
共通ブリーフ：最初の1.5秒で止める（フックを1フレーム目から）、15–25秒、アプリ機能はコードで確認、実キャプチャ、英語の発音はオーナーの登録声（ownvoice.py）、日本語TTSなし、2カット、Drive納品。途中追加：ミミの日本語の一人称は「僕」（本作のミミのセリフには一人称なし）。

## 判断

- **構成**：時系列のまま、フックの文字を最初から大きく置き、0.5秒でセリフ、1.53秒で「sh★t」、2.75秒でスクラッチ＋凍結。オチ→説明→アプリ→言い直し→エンドの順で18秒。
- **キャスト**：日本人側はミミの友だち、海外のお客さんは人種表現を避けて新キャラのクマ（Codex、[prompt](prompts/01-codex-cast-and-lobby.txt)）。ミミの驚き顔（両手でほっぺ）とロビー背景も同時に生成。
- **声**：友だちのセリフも含め英語はすべてオーナーの声。友だち（女の子っぽいキャラ）に男性の声が乗るミスマッチは許容（ブリーフどおり報告）。
  - `learner-shit`（1回目）：摩擦音の重心が約5kHzで s と sh の中間 → 不採用。
  - `learner-shit-2`（2回目、"sh as in she" を明示したスタイル）：摩擦音の重心 約4kHz（ネイティブの "sit" の s は約8.5kHz）で sh として聞こえる → 採用。Whisper は "sit" と書き起こす（言語モデルの補正と思われる）。Gemini の拒否はなし。
  - `native-sit`：`us` プリセット。
- **アプリ**：native-ios（origin/main 5998d20d）で確認した既存機能のみ。デイリーレッスンの画面（文、スコアのレーダー、全体のフィードバック、単語ごとの「直す音」カード：単語・IPA・説明・お手本/自分/練習/保存）、`lesson.model`（お手本＝自分の声のモデル）、`lesson.record`。キャプチャ専用パッチ `sit-lesson.patch` で QA フィクスチャの最初の文を "Please sit down." に、フィードバック対象を "sit"・音 "/s/"・説明文を差し替え（「QA用データ」表記も消える）。このフィードバック文は実際のAI出力ではなく作例。
- **キット**：`apply-patch.py` を複数ファイル・複数ハンクに対応（従来の1ハンクのパッチも同じ動作）。
- **シミュレータの制約**：録音停止後はオフラインのため「発音を採点できませんでした」になる → 54.5秒より前で切る。お手本ボタンのタップでは画面上の変化がないので、映像のタップ位置にオーナーの `native-sit` を鳴らした。
- **伏せ字**：画面は星「sh★t」、字幕も "sh*t"。

## 確認

`hyperframes check`：エラー0（警告はトラック密度など）。主要フレームを目視（process/00-final-frames.jpg）。ラウドネス約 -15 LUFS、声が最大、BGMは凍結中ゼロ。

## 修正 1（口のアイコン）

オーナー：「もう少し口の形っぽく」。比較カードの2つのアイコン（楕円／丸と点）を、正面から見た唇のイラストに描き直した。上唇のキューピッドボウ、下唇のツヤ、歯、舌。sit は横に引いた笑顔の形で歯が見え、舌先が歯の近くにあり、外向きの矢印を付けた。sh は丸めて突き出した唇で開口部が小さく丸く、内向きの矢印と、唇が前に出る横顔の小窓を付けた。ほかは変更なし。両カットを再書き出しし、Drive の前のドラフトは `old/`（`_v1-mouth-icons`）へ移した。新しいカード：[process/01-mouth-card.jpg](process/01-mouth-card.jpg)。2〜6話用の音ごとの口の形は README のシリーズテンプレートに追記。
