# Tokyo vs Osaka — あいさつの音を比べる。

左右の都市、紺と赤、声に合わせた明暗。音の違いを聞きながら、同じ言葉のアクセントを線で追える比較動画です。

## 再制作の流れ

1. 東京→大阪の順で、各ペアの自然音声を配置する。
2. こんにちは・おはよう・ありがとう・おかえり・ただいまを比較する。
3. 発話中の側を明るくし、承認済みのピッチ線を固定表示する。
4. 音声の実測時間に字幕と動きを合わせる。別の題材で作る場合は、台本・声・キャラクターを自分が利用できるものに置き換える。
5. 9:16の画面で文字の欠け、字幕の先走り、音声の途切れを確認する。
