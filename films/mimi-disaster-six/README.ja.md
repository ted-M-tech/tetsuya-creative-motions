# Pronunciation Disasters 7 - Six / S*x

[English](README.md)

Lanclo SNS ショート #048（シリーズ「Pronunciation Disasters / 発音で大事故」第7話）。20.0秒、1080×1920、60fps、2カット（日本語のみ／英語字幕つき）。

場面：レストランの入口で、友だちが店員のピッパに「A table for six, please.」→「イ」が「エ」寄りに開いて sex に聞こえる。ピッパは真っ赤になって目を覆い、Mimiも赤面して飛び込む。

構成はパイロット（[mimi-disaster-sit](../mimi-disaster-sit/)）と同じ（第6話 [mimi-disaster-peace](../mimi-disaster-peace/) から複製）：1フレーム目にMimiのオチ（「それ、S★xに 聞こえてる」）→ 巻き戻し → 状況フック → 言い間違い → フリーズ → Mimiが飛び出す → 自分の声の2テイク比較カード＋口の形（/ɪ/ と /ɛ/）→ 実際のLanclo画面 → 言い直し → エンドカード＋CTAタップ。

- 声：学習者テイクとお手本はオーナーの登録済みLanclo音声（ownvoice.py）。学習者テイクは母音を /ɛ/ に編集（詳細は PROCESS.md）。WAVは生体データなのでGitに入れず、Drive `048. Pronunciation Disasters 7 - Six or Sx/Disasters7_Six_assets/own-voice/` に保管。ピッパはKokoro英語。
- 画面上の下品な単語は必ず★で伏せ字。音声では聞こえる（そこがオチ）。
- Mimiの一人称は「僕」。言い間違えるのは「友だち」、店員はサブキャストのアヒルのピッパ。
