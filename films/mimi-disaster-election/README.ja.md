# Pronunciation Disasters 4 - Election / Erection

[English](README.md)

Lanclo SNS ショート #040（シリーズ「Pronunciation Disasters / 発音で大事故」第4話）。20.0秒、1080×1920、60fps、2カット（日本語のみ／英語字幕つき）。ドラフト（未承認）。

場面：「会議で I can’t wait for the election → erection」

構成はパイロット（[mimi-disaster-sit](../mimi-disaster-sit/)）と同じ：1フレーム目にMimiのオチ（「それ、Er★ctionに 聞こえてる」）→ 巻き戻し → 状況フック → 言い間違い → フリーズ（小さなレコードスクラッチ）→ Mimiが飛び出す → 自分の声の2テイク比較カード＋口の形 → 実際のLanclo画面 → 言い直し → エンドカード＋CTAタップ。

- 声：学習者テイクとお手本はオーナーの登録済みLanclo音声（ownvoice.py、Gemini gemini-3.8-flash-tts）。WAVは生体データなのでGitに入れず、Drive `040. Pronunciation Disasters 4 - Election or Erection/Disasters4_Election_assets/own-voice/` に保管。相手役はKokoro英語。
- 画面上の下品な単語は必ず★で伏せ字。音声では聞こえる（そこがオチ）。
- Mimiの一人称は「僕」。言い間違えるのは毎回「友だち」、他の役は共通サブキャスト（kits/mimi-short/cast：クマのブルーノ／アヒルのピッパ／ネコのココ）。
