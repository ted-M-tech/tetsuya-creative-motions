# 制作の経緯

Notion Content Calendar ID 24。オーナーの言葉（原文）：

> 9.「Mimiはずっとあなたの成長をみてるよ・・・」って最初にホラー風

承認された構成（親セッション経由、約18秒）：0–2秒 ホラー風フック（暗い部屋、スマホだけ光る、ノイズと低いドローン＝大きな音は嫌い、暗がりにMimiの目、ささやき字幕）→ 2–4秒 通知が届き、友だちがおそるおそる開く → 4–11秒 実アプリのMimiのアドバイス（言い回しの癖、くり返す発音の癖 → ネイティブならの言い方）、友だち「…なんで知ってるの」→ 11–13秒 明かりがつき Mimi「毎日ちゃんと見てるから、伸びるんだよ！」→ 13–15秒 コピー「見られてるから、続く。」→ 15–17秒「…じゃあサボった日も？」Mimiは黙って笑い、また暗くなる → 17–18秒 エンドカード。

## 判断

- アプリの事実（Lanclo `docs/features/mimi-ai.md`、`PracticeReminder.swift`）：
  - まとめは練習リマインダーの時刻（初期値20:00）に1日1回、本人の日記と録音の評価から。通知は2つ目を作らず、気づきがある日はリマインダーの文言が変わる。日本語は `Localizable.xcstrings` の「Mimiが今日のまとめで気づいたことがあるよ。見てみよう！」、タイトル「Mimi · Lanclo」、添付はMimiListeningの絵。ロック画面はこれをHTMLで描いた（実機の通知の録画ではない）。日付はレポートの「10月20日(火)のまとめ」に合わせた。
  - 字幕「20:00 いつもの練習リマインダーの時間」で、Mimiが勝手に来るのではなく自分で決めた時刻だとわかるようにした。
  - 明るい場面の注記は「※Mimiのまとめは、あなたの日記と練習の録音から」。発音の順位はレッスンプランのランキング（サーバー）から来るので「端末の中だけで」とは書かなかった。監視・データ収集をにおわせる言葉は使っていない。
- 実画面：mimi-loop で録った `--qa-mimi` のテイク（Drive 018 `Loop_assets/`、Lanclo 03ea125d）を再利用し、新しい録画はしなかった。そのあとのLanclo main の変更（初回レポートの紹介）は、このフィクスチャのレポート画面の見た目には関係しない範囲と判断。画面の言葉：Mimiのアドバイス／あなたの癖／ボキャブラリー “And then” 4回／発音 /l/ 録音4／ほかの言い方 “After that,”／ネイティブなら “After lunch, Ken and I headed to the station.”。
- フィクスチャの「デモ：…」の説明（ネイティブならカード）は、カードの色（#e8eef6）でマスク。16倍速のスクロール（8.5–9.0秒）では他のカードの「デモ：」が流れるので、その間だけ画面をぼかした（blur 9px）。
- 「くり返す発音の癖」は発音ランキングの /l/（録音4回）で見せた。このテイクは発音の詳細までスクロールしていないため、詳細カードは出していない。
- 新しいポーズは codex-p で3つ（`prompts/01-codex-poses.txt`）：のぞくMimi（暗がりでは明るさを落とし、目の位置に光る点を重ねた）、目を閉じてにっこりのMimi、スマホを持って固まる友だち。冒頭のベッドの友だちは mimi-loop の friend-bed を写した。
- 音：大きな音は避けた。ドローン（110Hz付近のゆっくりうなる音＋ヒス）は暗い場面の下にごく小さく、フックと「なんで知ってるの」と最後の暗転で少しだけ上げる。テーマBGMは明かりがつく11.4秒から、暗転中は小さく下げ、エンドカードで戻す。
- 暗い場面のノイズは canvas に時間から決まる乱数で描く（書き出しで毎回同じになる）。

## 第2版（コーディネーターの確認）

コーディネーターの指摘（要旨）：秒ごとの音量が0–3秒で −16/−12/−13 dB、アプリの部分は −18〜−20 dB。暗い冒頭がいちばん大きく、オーナーは大きなSFXが嫌い。暗い場面のドローン・ノイズを6〜8 dB下げ、冒頭がアプリの部分以下になるように。16倍速スクロールの「デモ：」も隠せるなら隠す。

判断：
- 原因はキットの `Mix.write` の最後の1パス loudnorm（動的）。声のない作品では静かな冒頭を15 dBほど持ち上げていた。この作品の `mix.py` は同じバスの比率で書き出し、作品全体に1つのゲイン（−14 LUFS）とピークリミッターをかける形にした（キットは変えていない）。
- あわせてドローン、目のwhoosh、通知のdingを小さくした。秒ごとの音量（dB RMS）：0–3秒 −29/−25/−27、アプリ −20〜−33、明るい場面 −10〜−13、再暗転 −17。
- 8.5–9.0秒のスクロールはぼかした。

## 第3版（オーナーの手直し）

オーナーの言葉（原文、コーディネーター経由）：

> 自分では気づかない癖をMimiは見つけてくれる。どうしても決まった表現、単語ばっかり使ってしまう。それ、僕が指摘してネイティブならこう言うよ、って教えてあげる。そしてそれは君の復習リストに入れれるよ、だから『僕のことずーーーーーーっと忘れないでね・・・』みたいな感じで

コーディネーターの指示（要旨）：コピー「見られてるから、続く。」は弱い。明かりがついた後をやり直す：Mimiが2〜3枚で説明（気づかない癖→同じ表現・単語ばかり（“And then” ×4）→ネイティブならこう言う）→しおりで復習リストへ保存（保存後の画面は作らない、飛ぶチップは可）。コピーを差し替え。最後は「サボった日」をやめ、ホラーの暗さに戻ってMimiの目が光り「だから…僕のこと、ずーーーーーーっと忘れないでね…」（ーを見た目でのばす）→エンドカード。音は第2版の静かさのまま。

判断：
- 説明の画面は、同じ `--qa-mimi` テイクの静止画2枚（`scripts/app_track.sh` の habit.png / native.png）。ボキャブラリーの “And then” 4回と、ネイティブならカード（「デモ：」の行の上で切った）。
- 保存：アプリの仕様では、Mimiのアドバイスのフレーズはしおりボタン（SavedNoteButton）でマイノートに保存でき、マイノートには復習（SRS）がある（docs/features/mimi-ai.md、official-word-decks-validation.md）。カードの実物のしおりボタンに波紋を出し、「＋ マイノート（復習リスト）」のチップを飛ばした。保存した瞬間・保存後の画面は録っていないので作っていない。
- コピーは「気づかない癖まで、Mimiが見つける。」。
- 最後のささやきの「ーーー」は文字を並べず、光る線が0.85秒でのびる形にした。Mimiは一人称「僕」（オーナーの言葉どおり）。
- 説明の3ビートと新しいラストが入り、尺は22.0秒。
- 新しいポーズは作らず、ライブラリの point（指さし）と confident（自信）を使った。

## 第4版（ホラーBGM）

オーナーの言葉（原文、コーディネーター経由）：

> 24ホラーシーンのところはホラーっぽいBGMで

判断：
- 暗い場面（0–11.4秒のフック、17.9–20.6秒のささやき）のドローンをやめ、コードで作ったホラーのBGMにした（`scripts/mix.py` の `horror_bed`、外部素材なし）：
  - 少し音程の狂ったオルゴールの子守歌（Aマイナー、72 BPM、E C A C｜B G# E、1オクターブ下を小さく重ねる）。進むほどテンポが遅れ、音程が下がる。「…なんで知ってるの」（10.3秒）で1音だけ外れた音（D#）。
  - 心音（ドクン・ドクン、66→84 BPMに少しずつ速く）。
  - 不協和な弦の和音（A2・B♭2・E3・E♭4）が「なんで知ってるの」に向けてふくらむ。
  - 全体をローパス（約1.5–2 kHz）で高い音を出さない。大きなスティンガーはなし。明かりのスイッチ（11.4秒）でぶつっと無音にし、明るいテーマBGM（Everyone Get Up）と対比させる。最後のささやきは子守歌の最初の3音をゆっくり・低く、心音2つ。
- 音量は第2版の方式のまま（作品全体に1つのゲイン −14 LUFS＋ピークリミッター、場面ごとの持ち上げなし）。ホラーBGMは専用のバス（`HORROR_GAIN = 0.42`）で、暗い場面がテーマBGMの場面より約2 LU小さくなるように合わせた。
- 測定（書き出したMP4、EBU R128）：

  | 場面 | 第3版 | 第4版 |
  |---|---|---|
  | 0–11.4 暗いフック | −24.1 LUFS | −14.9 LUFS（最大モーメンタリー −11.3） |
  | 11.4–17.9 明るい場面（テーマ） | −12.6 | −12.8（−8.5） |
  | 17.9–20.6 ささやき | −27.1 | −14.9（−12.5） |
  | 20.6–22.0 エンドカード | −18.4 | −18.6 |
  | 全体 | −14.3 | −14.2、トゥルーピーク −1.3 dBFS |

  暗い場面の4 kHz以上の成分は0.3%以下（明るい場面1.7%）。11.4秒の切り替えは無音の谷のあと明るい場面へ。

## 学んだこと

- 声のない作品では、キットの1パス loudnorm が静かな部分を大きく持ち上げる。秒ごとの音量を測ってから渡す。
- 「ホラーっぽく」は小さいドローンだけでは伝わらない。メロディ（狂ったオルゴール）と心音があると、小さい音量でもホラーとわかる。

- GSAP の `fromTo` は作った時点で from の値を描く。後半に使う白フラッシュ（opacity 0.9→0）が冒頭から画面を白く覆った。`immediateRender: false` で直した。
- 共有のscratchpadでは兄弟ワーカーと同じファイル名（k00.png など）がぶつかる。作品ごとのサブフォルダを使う。
