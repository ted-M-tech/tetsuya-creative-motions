# 制作の経緯

オーナーの言葉（コーディネーター経由の依頼。キャスト：Mimi＝創業者、カナダ在住の日本人／フランス風の友だち＝大学の語学講師）：

1. カナダのマラソン（紅葉、ランナー、ゼッケン）。たまたまMimiが講師の隣を走る。
2. Mimi：「カナダに住んでる自分が実際にやってる勉強をアプリにしてるんだよね。いろんな勉強法を試してきたけど、自分このみでやりたくて」（走りながら短い吹き出し2つに分ける）
3. 講師：「いいね！僕が大学講師目線で、言語学習に使えるようにアドバイスするよ！」
4. レース後のカフェ：時計が回って3時間の話（カップが積み上がる）→ オンライン通話（ノートPC、メモ、アプリのスケッチ）。
5. 「できた！いぇーい！」— Lanclo誕生（マーク、できれば実アプリのホーム画面を少し、紙吹雪／ハイタッチ）。
6. メッセージ：「Lancloは、みんなの声で育つアプリ。」→「使ってみて、Mimiに要望を教えてね！」→ Mimi（少し汗）「お手柔らかに…」→ エンドカード。
- 実名・顔・実在の大会名は出さない。温かく楽しいトーン（テーマBGM、やさしいSFX：足音、カフェのカチャ、キーボード、歓声）。
- 要望の送り方：アプリにフィードバック／問い合わせの入口（例：設定 › ヘルプとアプリ情報）があるか確認し、あれば正確に小さく書く。なければ「アプリやSNSで」程度に。

途中の更新（オーナー）：「旗はOK（例：大会にカナダのメープルリーフの旗、キャラクターに日本／フランスの小さな要素も可）。大会名は出してよい：カナダのビクトリアマラソン（English: the Victoria Marathon, Canada）。公式ロゴではなく文字（横断幕／字幕）で。実在の人の名前や顔は引き続きなし。」

判断：

- ほぼアニメーション。新しい絵（Mimiと講師の走り、講師のサムズアップ、カフェで向かい合う2人、ノートPCのMimi、通話画面の講師、ハイタッチ、汗のMimi、コーヒーカップ、紅葉の大会コースと夜のデスクの背景）は codex-p で公式アートと友だちのデザインから作画（`prompts/01-codex-art.txt`）。カフェの背景は `films/mimi-roleplay` のものを再利用。
- 講師はフランス風：友だち（オレンジの目元、灰色の耳先）に紺のベレー帽とボーダー。並行して作業していた mimi-freespeech のフランス風の友だちの絵は、着手時にまだなかったので独自に描いた。
- 日本の要素：Mimiのゼッケン（1024）の角に小さな日の丸。カナダの要素：コース柵のメープルリーフの旗。大会名は無地の横断幕に「VICTORIA MARATHON」の文字、字幕に「カナダのビクトリアマラソン」。
- 走る場面：背景は奥へ伸びる道なので横スクロールではなくゆっくりズーム＋落ち葉、2人は足踏みのリズムで上下。講師が後ろから並び「たまたま隣を走っていたのは…」＋タグ「大学の語学講師」。
- カフェ：壁の時計が3周し「＋3時間」、テーブルにカップが6つピラミッドに積み上がる（SFXはカップの音）。
- オンライン：通話ウィンドウ（「オンライン通話」）の講師、Mimiはノートで作業、付せん「毎日続けたい」「自分の声で」とアプリ画面の手描きスケッチが増える。付せんの文言は演出（Lancloの毎日のレッスンと自分のAIボイスに対応）。
- アプリ：テスト用データでホーム画面をシミュレーター録画（`source/app-capture/HomeWalkthrough.swift`）。「リリース！」とLancloのマーク。
- 要望の入口：アプリの 設定 › ヘルプとアプリ情報 に「サポート」（lanclo.app/legal/support.html、サポートにメールする）がある。専用のフィードバック機能ではないので「要望はアプリの 設定 › ヘルプとアプリ情報 › サポート から」と小さく書いた（Lanclo origin/main e33cd888 の `AccountProgress.swift` aboutPage と Localizable の日本語ラベルで確認）。
- 声なし（日本語は吹き出しのみ）。音はテーマBGM、足音、遠くの歓声、カップ、時計の針、キーボード、通話のチャイム、紙吹雪と小さな歓声、CTAにpochi。
- 長さ：依頼は約30秒。台詞の読み時間を確保して32秒。

学び：遠近のある道の背景では横スクロールが不自然。ズームと落ち葉で「走っている」感じが出る。
