# Lancloのはじまり

[English](README.md) · **日本語**

カナダのビクトリアマラソンで、Mimi（創業者。カナダ在住の日本人）がたまたま大学の語学講師（赤いベレー帽・スカーフとボーダーの友だち）の隣を走る →「カナダに住んでる自分が実際にやってる勉強をアプリにしてるんだよね」「いろんな勉強法を試してきたけど、自分このみでやりたくて」→ 講師「いいね！僕が大学講師目線で、言語学習に使えるようにアドバイスするよ！」→ レース後のカフェで3時間（時計が回り、カップが積み上がる）→ オンライン通話でメモとアプリのスケッチ →「できた！いぇーい！」（ハイタッチと紙吹雪）→ Lancloのマークと実アプリのホーム画面 →「Lancloは、みんなの声で育つアプリ。」「使ってみて、Mimiに要望を教えてね！」→ Mimi（汗）「お手柔らかに…」→ エンドカード。32秒、1080×1920、60fps。日本語のみ版と英語字幕版の2本。

2本：日本語のみ（`mimi-origin.mp4`）と英語字幕つき（`mimi-origin-en.mp4`）。完成版はLancloのGoogleドライブ `002.SNS/025. How Lanclo Began/`（`Origin_2026-10-21.mp4`、`Origin_EN-subs_2026-10-21.mp4`、録画の原本は `Origin_assets/`）。
