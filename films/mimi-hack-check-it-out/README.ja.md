# 発音のコツ 1 - Check It Out

[English](README.md)

Lanclo SNSショート #072。新シリーズ「Pronunciation Hacks（発音のコツ）」第1話（毎回、短く正しいコツを1つ。最後に「次のコツは？」）。完成版（2026-10-23、オーナー承認済み）。15.2秒、1080×1920、60fps、2本（日本語のみ／英語字幕つき）。

コツ：**リンキング**。語末の子音が次の語の母音につながる（check‿it‿out、pick‿it‿up）。この回は子音→母音のリンキングだけ（フラップTは扱わない）。

会議室。1フレーム目から「チェケラ ＝ Check it out」、なめらかなお手本が流れる。友だちがロボットのように「Check. It. Out.」と1語ずつ（オーナーの声・学習者スタイル、本当に間があく）。ミミのカード：「最後の子音 ＋ 次の母音は つなげて読む」、k‿i と t‿o に弧を描き、お手本「Check it out!」、続けて「Pick it up!」。部屋に戻って友だちがなめらかに言えてハイタッチ。「次のコツは？」のあとエンドカード。

| 秒 | ビート | 内容 |
|---|---|---|
| 0.00–2.00 | `hook` | 「チェケラ ＝ Check it out」「つなげて読むコツ」、0.2秒にお手本 |
| 2.00–5.10 | `slip` | 学習者テイク「Check. It. Out.」（語の間に約0.54秒の無音）、「1語ずつ読むと…」「カクカク…」 |
| 5.10–7.30 | `tip` | カード：ルール、Check it out の弧、お手本、お手本＝自分の声 |
| 7.30–9.00 | `model` | Pick it up の弧とお手本、「3語 → ひとかたまり すき間なし」 |
| 9.00–11.80 | `fix` | 友だちがなめらかに「Check it out!」、「つなげたら → なめらか！」、ハイタッチ |
| 11.80–13.60 | `cta` | 「次のコツは？」「知りたい発音、コメントで！」 |
