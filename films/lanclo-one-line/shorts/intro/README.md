# アプリ紹介ショート（Notion Content Calendar ID 10「アプリ紹介」）

自分の英語が「日本語に聞こえる」問題から入り、自分の声のネイティブ発音 → 5つの視点の採点と直す音 → 17言語 → CTA までを30秒で見せる、Lanclo の紹介ショート。PV と同じ「一本の線」の絵作り。

0:30 / 1080×1920・60fps / Mimi の関西弁ナレーション（1.2倍速）＋大阪弁の文字 / Python・pycairo・numpy（全フレームをコードで描画）

17言語はアプリの学習言語（`packages/core/src/studyLanguages.ts`）と同じ。あいさつは PIL では複合文字（デーヴァナーガリー、ベンガル、タイ）が崩れるため、`scripts/greetings.swift`（CoreText）で `assets/greet/*.png` に書き出したもの。

## 音

- 声が主役。ナレーションは `scripts/intro_vo.sh` で Mimi.m4a から10行を切り出し、1.2倍速（音程そのまま）。各行は最後の音から約0.12秒あとで切る（語尾が欠けないように）。
- LP の比較クリップは "available" の語尾まで（単語の終了時刻より実際の音が約0.2秒長い）。
- BGM は Lanclo SNS のテーマ曲「Everyone Get Up」（[CREDITS](../../CREDITS.md)）。ナレーションより約21dB下。録音カードで下げ、比較中は無音、見出しで戻す。最後の声のあとフェードアウト。
- 効果音はコードで作る。高いベル（ピロリーン）は1オクターブ下げて約1/3の音量。

## 制作の経緯（依頼者の指示）

- 「この動画作れる？同じようなアニメのクオリティ」（Notion「アプリ紹介」の台本、One line PV と同じ質感）
- 「この音・声の列無視されてるのなぜ？30秒に収める。1.2倍速くらいかな？」→ 切り出しの不具合（`-ss/-to` と `afade` の組み合わせで2行目以降が無音）を直し、`atrim` に変更
- ナレーションを Kansai.m4a から「ごめん、こっちで」Mimi.m4a へ
- 別セッション経由のフィードバック：「音声デカくて聞こえづらい」「最初…Mimiおっきく出して指差しして、視聴者に訴えかける」「てつやの録音シーンと、AIてつの声の最後が途切れてる」「0:21~『英語も〜』からのところは、多言語対応であることをアピールする映像に変更」「音声最後途切れてるので入れて」
- 「背景音まだ少し大きい…効果音も。あと文字は大阪弁にして。あとbgmもう少しふざける感じでよい」
- 「BGMこれにして。これをLancloSNSのテーマとして今後も使ってく」「ピロリーンがでかくてびっくりした」→ テーマ曲に差し替え、ベルを下げる
- 「いいね。では一旦これで保存して整理。mainに入れて」

学んだこと：単語タイムスタンプの終了時刻で切ると語尾が欠ける（実際の音で確かめる）。イヤホンでは高いベルが突き刺さる。BGM はナレーションより約20dB下が目安。
