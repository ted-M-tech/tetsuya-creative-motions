# Lanclo One line — 1本の線で、全部見せる。

[English](README.md) · **日本語**

1本の声の線が、ロゴ → 自分の声とお手本 → 5視点レーダー → 次の練習 → 4つの練習 → ロゴを描いていくナレーションなしのPV（16:9・0:26）と、同じ作りの英語日記ショート（9:16・0:22）。全フレームと音をPython（pycairo・numpy）で生成。
