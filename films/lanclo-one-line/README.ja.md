# Lanclo One line — 1本の線で、全部見せる。

[English](README.md) · **日本語**

1本の声の線が、ロゴ → 自分の声とお手本 → 5視点レーダー → 次の練習 → 4つの練習 → コピー → ロゴを描いていく短いPVと、同じ作りの機能紹介ショート（9:16）。ナレーションなしで、画面の日本語と英語字幕で伝えます。

PV 0:26（16:9）/ 英語日記ショート 0:22（9:16）/ 1080p・60fps / Python・pycairo・numpy（全フレームと音をコードで生成）

## 作品

- **PV**（16:9）：自分の声で、ネイティブの発音を。
- **[英語日記](shorts/journal/README.md)**（9:16）：声で記録し、添削とイラストを受け取り、カレンダーに並べる。

## 狙いと制作の判断

- Duolingoのスペック広告プロンプト "The Path" の構成（1本の線、カメラ移動、マスコットの叩きつけ）を借り、色・キャラクター・コピーをLancloへ置き換えた。
- 最初は日本語ナレーションを録ったが、文字だけの方がテンポが出てSNSで無音再生されても伝わるため不採用。代わりに見出しの読む時間を絵の「止め」で確保した。
- 声で伝える部分は、LPと同じ英語の聴き比べ（本人の声 / お手本）だけを使う。
- デモの値・文言を出す画面には「デモ表示」と入れる。
- 機能ショートは1本1機能、縦に積んだ駅をカメラが下る。SNSのUIで隠れる下部を避けて字幕を置く。
