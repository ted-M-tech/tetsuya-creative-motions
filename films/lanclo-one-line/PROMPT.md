# 再制作用の統合プロンプト — Lanclo One line

完成版の判断を統合したプロンプトです。最初の一回の入力原文ではありません。参考にしたのは Duolingo のスペック広告プロンプト "The Path"（1本の線とカメラの移動で全機能を通す構成）。その構成を借り、題材・色・キャラクター・コピーをLancloに置き換えました。

自分の製品で作るときは、**[置き換える]** の箇所を差し替えてください。

---

## 共通の約束（PV・機能ショートとも）

- **全部コードで描く。** Python + pycairo で毎フレームを描き、ffmpeg にパイプする。動画生成AI・テンプレート・素材動画は使わない。BGMと効果音も numpy で合成する。
- **1本の線が主役。** 画面の最初から最後まで、同じ太さ・同じ色・先端に光る点を持つ1本の線が描かれ続ける。ロゴの下線 → 波形 → グラフの枠 → 分岐 → 再びロゴの下線。シーンの切り替えは、この線の先をカメラが追う移動だけで行う（カット・フェードで場面を変えない）。
- **キャラクターは「叩きつけ」で始める。** 0.17秒で奥から飛び込んで着地、押しつぶし＋戻りのバネ、紙片が散る、画面が揺れる。これがフック。終盤にもう一度、同じキャラクターが線の上に着地して終わる。
- **ナレーションなし。文字で語る。** 各シーンに2行の日本語見出し。1行目は普通の色、2行目（または強調語）はブランド色。行ごとに0.45秒ずらして下から浮き上がる。英語字幕は画面下に、見出しの訳として見出しが出ている間だけ出す。
- **読む時間を守る。** 見出しが出てから次の移動まで、2行で最低2.0秒。足りない場合は絵を止めて時間を足す（timeline.py の `WARP`）。BGMは止めずに一定テンポのまま流す。
- **数字は動かす。** スコアはカウントアップ、チップは順番にポップ。デモ値を出すときは画面に「デモ表示」と明記する。
- **音は絵に合わせて全部置く。** 移動ごとにwhoosh、出現ごとにpop（後ろほど音程を上げる）、着地にimpact、締めに4音のファンファーレ。BGMは100 BPM、Dメジャー（D–Bm–G–A）、マレット＋パッド＋サブベース。中盤からキック・クラップ・シェイカーで前に出し、最後の着地の直前に一拍の「息継ぎ」（逆再生のスウェル）。-14 LUFS / -1.5 dBTP に正規化。
- **紙と墨の配色。** 背景はほぼ白（#FBFCFD）にぼかした淡い丸（#EAF1F6）を視差で流し、全体に細かい粒子ノイズ。文字は #273B4B、線と主要な面は #344F69、強調は #5B7F9F、注意・取り消しは #F4A9B8。**[置き換える：自社ブランドの色]**
- **書体は1種類。** Zen Maru Gothic（Regular / Medium / Bold）。
- **締めはロゴと行動。** ロゴ（マーク＋ワードマーク）を線の先端が左から描き出す → キャラクター着地 → コピー → 「7日間無料ではじめる」＋App Storeバッジ＋URL。**[置き換える：自社のCTA]**

## 機能ショート（9:16、1080×1920、60fps、約22秒）

同じ約束のまま、縦に積んだ駅をカメラが下へ移動していく形にする。1本1機能。

- 駅は縦方向に約2,000pxずつ。線は駅と駅の間を画面の右端（または左端）の余白に沿って下り、見出しの文字と重ならない。
- 見出しは画面の上から約1/3まで。カード類は中央。**下から約400pxはSNSのボタン・説明文で隠れる**ので、英語字幕はその上の帯に置き、カードはそこまで下げない。
- 見出しは76px、2行。字幕は38px、幅860pxで自動改行。
- 構成は「問いかけ → 体験 → 結果 → うれしさの蓄積 → ロゴとCTA」。各駅3〜4秒、移動0.75秒。

例：[英語日記](shorts/journal/README.md)

## 自分の製品に置き換える手順

1. 製品のいちばん短い約束を2行の問いにする（PVの2）。
2. 「線が何に変わるか」を機能ごとに決める。声なら波形、評価ならレーダーの枠、選択肢なら分岐、記録ならカレンダーへの飛び込み。
3. 機能ごとに「2行見出し＋英語字幕」を書き、読む時間を2秒以上確保する。
4. キャラクター画像（透過PNG、表情違い3〜5枚）、ロゴ、写真、フォントを `source/assets/` に置く。
5. `timeline.py` の拍を先に決め、絵（render.py）と音（audio.py）の両方がそこから読む。
6. 静止画（`--still`）で全シーンを確認 → 低解像度で通し → 本番書き出し。
