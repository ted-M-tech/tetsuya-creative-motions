# Lanclo One line — one line shows it all

**English** · [日本語](README.ja.md)

A no-narration promo (16:9, 0:26) where one voice line draws the logo, your voice vs. the model, a five-axis radar, the next practice, four practice modes and the logo again, plus an English journal short (9:16, 0:22) built the same way. Every frame and sound generated in Python (pycairo, numpy).

![Promo](media/promo.jpg)
![English journal](media/journal.jpg)

- Structure borrowed from Duolingo's spec ad "The Path" (one line, camera flight, mascot slam).
- Reusable style: [One line](../../styles/one-line/STYLE.md)

The full prompts, making-of and source are shared privately.
