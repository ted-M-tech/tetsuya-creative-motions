# 自分の声、むり — Mimi 2Dショート

[English](README.md) · **日本語**

録音した自分の英語が恥ずかしいMimiが、「自分の声のお手本」を聴いて驚き、お手本に合わせて練習し、点数と直すポイントで納得するまで。Lancloの核の価値を15秒で見せる縦型ショート。

0:15 / 1080×1920・60 fps / 日本語の字幕・英語の声 / 2D：Codexで描いた公式の絵柄＋Riveの骨＋HyperFrames
