# 自分の声、むり — Mimi 2Dショート

[English](README.md) · **日本語**

録音した自分の英語が恥ずかしいMimiが、「自分の声のお手本」で驚き、お手本に合わせて練習し、点数と直すポイントで納得するまで。0:15・1080×1920・60 fps。公式の絵柄をCodexで描き足し、Riveの骨で動かし、HyperFramesで仕上げた2Dアニメ。
