# 再制作用の統合プロンプト — 「日記、3日で終わる」

完成版の判断を1つの指示にまとめたものです。最初に入力した原文ではありません（経過は [PROCESS.md](PROCESS.md)）。共通キット [kits/mimi-short](../../kits/mimi-short/README.md) を使う前提です。別の機能の回で使うときは **[置き換える]** を差し替えてください。

---

LancloのマスコットMimiが主役の、15秒の縦型ショート（1080×1920、60 fps）を、承認済みの2Dイラストの絵柄のまま、共通キット `kits/mimi-short` で作る。ナレーションなし。日本語の字幕は上部、下端約400 pxは空ける。

## 話（[置き換える：機能と、その機能だから続く理由]）

**ことわざを文字どおりに見せる → 機能が「続く理由」になる。** 三日坊主を本当のお坊さんで見せ、英語日記は「話すだけ」「直る」「自分の声で聴ける」「その日が絵になって見返すのが楽しい」から続く、で締める。機能紹介の回では、機能の一番楽しいところ（ここでは絵）をオチの理由にする。

| 秒 | 画面 | 字幕／音 |
|---|---|---|
| 0–1.0 | お坊さんMimiが木魚を3回 | 「英語日記、3日で終了。」→「三日坊主。」（大きく）／木魚×3 |
| 1.0–2.4 | 白紙の紙の日記の前でしょんぼり | 「英語で書くの、しんどい…」 |
| 2.4–3.1 | 英語日記のマイクをタップ | タップ |
| 3.1–4.9 | 話すだけ（口パク） | 「書かなくていい。話すだけ。」、「① 英語日記に話す」／"Yesterday... I go to cafe." |
| 4.9–6.4 | 日記チェック：レーダー（文法が赤）、66点、「go → went」を大きく、「昨日のことは過去形」 | 「自然な英語に、直してくれる。」 |
| 6.4–8.0 | 聴く | 「直した日記を、自分の声で。」、「② ▶ 自分の声のお手本」／自分の声の "Yesterday, I went to a cafe." |
| 8.0–9.8 | 絵描きMimiが筆をふり、額の中にカフェの絵が上から描き上がる（0.7秒） | 「その日が、Mimiの絵に。」／鉛筆の音、ベル |
| 9.8–14.0 | 絵のカレンダー（3×2）：1–3日目は本・PC・公園、4日目にカフェ（青枠で強調）、5・6日目が続いて「6日連続」。ジャンプ、ガッツポーズ、最後はウインク | 「絵日記みたいに、見返すのが楽しい。」→ 12.4「三日坊主、卒業。」 |
| 14.0–15.0 | キットのエンドカード | 締めの和音 |

## 絵

- 新しく描くもの：お坊さんのポーズ（灰色の簡素な衣、木魚と撥、目を閉じた諦め顔、宗教的な図像にしない）、紙の日記（[prompts/01-codex-bozu-notebook.txt](prompts/01-codex-bozu-notebook.txt)）。
- 絵描きMimiはアプリの公式イラスト（`artist.webp`）が334 pxと小さいので、同じデザインで描き直す（[prompts/03-codex-artist-hires.txt](prompts/03-codex-artist-hires.txt)）。
- 日記の絵はアプリの英語日記の見本の絵を使う（カフェ・公園・PC・本・靴・ラーメン）。

## 動き・編集・音

- 作品の演技：木魚（撥の手を3回振り下ろす）、話す（口パク）、絵を描く（筆の手を3回振る）、得意げ。
- 絵は `clip-path` で上から現す。カレンダーは「卒業」の場面でも出したままにして、主張と証拠を同じ画面に置く。
- 声はKokoro（`af_heart`）。効果音はキットの `mokugyo()`・`pencil()`・`pop_seq()` ほか。
