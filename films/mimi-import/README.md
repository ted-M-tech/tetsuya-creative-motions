# Mimi eats your files — a 2D Mimi short (CSV import)

**English** · [日本語](README.ja.md)

Mimi's friend has the phrases she wants to learn scattered over a spreadsheet, a text memo and a list an AI made for her. Mimi: "Excel? A memo? An AI's list? Turn them into a CSV…" — the three lists fly together into one file (`旅行フレーズ.csv`), My Notes' real import sheet shows「CSVファイルを選ぶ」, and Mimi gobbles the file up (「Mimiが食べるわ！」) while the rows fly out as crumbs. The crumbs rain into the phone: Lanclo's real preview (新しく追加できるノート 12件) → 12件を追加しました。→ a new 旅行 folder with 12 notes in My Notes → the review card with the model voice. Copy:「好きな内容を、ここで練習。」 Close: the friend「自分の好きなフレーズで練習できる！」, Mimi「ごちそうさま〜♪」.

0:17.4 / 1080×1920, 60 fps / Japanese speech bubbles and captions, one English phrase (the model, in the owner's own registered Lanclo voice) / official 2D poses + GSAP, real app (simulator) + HyperFrames

Two cuts: Japanese only (`mimi-import.mp4`) and with English subtitles (`mimi-import-en.mp4`); drafts in Lanclo's Google Drive `002.SNS/020. Mimi Eats Your Files/` (`Import_draft_2026-10-21.mp4`, `Import_draft_EN-subs_2026-10-21.mp4`, raw take in `Import_assets/`).
