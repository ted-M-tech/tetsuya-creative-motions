# Mimiがファイルを食べる（CSVの読み込み）

[English](README.md) · **日本語**

覚えたいフレーズがExcel・メモ・AIに作ってもらったリストにバラバラ → Mimi「Excel？メモ？AIのリスト？CSVにしたら…」→ 実アプリのマイノート「CSVファイルを選ぶ」→ Mimiがファイルをむしゃむしゃ「Mimiが食べるわ！」（行がくずになって飛ぶ）→ 実アプリのプレビュー「新しく追加できるノート 12件」→「12件を追加しました。」→ マイノートに「旅行」12件 → お手本つきの復習カード → コピー「好きな内容を、ここで練習。」→ 友だち「自分の好きなフレーズで練習できる！」Mimi「ごちそうさま〜♪」→ エンドカード。17.4秒、1080×1920、60fps。日本語のみ版と英語字幕版の2本。
