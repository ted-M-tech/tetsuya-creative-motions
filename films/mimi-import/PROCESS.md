# 制作の経緯

オーナーの言葉：

- 「CSV？テキスト？あなたのExcelとか、AIで変換させてMimiが食べるわ！って。Mimiがファイルを食べてインポートしているような描写に。自分の好きな内容をAIとかで作って取り込んで、ここで練習もできるでとか。」

判断：

- 話の形：友だちのフレーズがExcel・テキストのメモ・AIに作ってもらったリストにバラバラ → CSVにまとめる → Mimiがファイルを食べる（大きなコミックの食べっぷり、くず＝行）→ 行がマイノートに入る（実アプリ）→ お手本で練習・復習。コピーは「好きな内容を、ここで練習。」。
- Lancloが読み込めるのはLanclo用のノートCSVの1形式だけ（`docs/features/note-csv-import.md`）。表計算・テキスト・AIの出力は「CSVにする」と言うだけにして、他の形式を直接読めるとは言わない。単語帳アプリの名前は出さない。
- 「食べる」＝ファイルを選ぶ瞬間：実アプリの「CSVファイルを選ぶ」をタップした直後に食べる場面へ切り替え、システムのファイル選択画面は見せない（実際には録画内で「このiPhone内」から `旅行フレーズ.csv` を選んでいる）。
- CSVの読み込みはログインした人だけの機能（2026-10-19 オーナー決定）。iOSのUIテストにはログイン済みのフィクスチャがないため、録画用の作業コピーだけに `--qa-film-import`（テスト用ゲストをログイン扱いにして読み込みを通す）を足した（`source/app-capture/note-import.patch`、アプリ本体は変更なし）。画面下に「※CSVの読み込みはログインして使えます（画面はテスト用データ）」を常に表示。
- 読み込んだのは自作の旅行フレーズ12行（`source/app-capture/旅行フレーズ.csv`、term/meaning/example/example_translation/tags、タグ「旅行」）。シミュレーターの「ファイル」（このiPhone内）に一時的に置いて、実際のファイル選択 → プレビュー → 追加まで通した（録画後に削除）。
- 画面の文言はアプリの日本語のまま：CSVからノートを読み込む／CSVファイルを選ぶ／新しく追加できるノート 12件／12件を追加／12件を追加しました。／旅行 12／学習開始。
- 復習カードは「Could I have the check?」が最初に出た（順番はアプリ任せ）。録画には音がないため、お手本の声は Kokoro af_bella（①以来の友だちの英語の声）で置き換えた（演出上の置き換え）。日本語の台詞は吹き出し（KokoroのJF声は崩れるため）。
- 新しいポーズ5枚（友だち：バラバラで混乱／やる気、Mimi：大口でぱくっ／もぐもぐ／ごちそうさま）は codex-p で公式アートと友だちの既存ポーズから作画（`prompts/01-codex-poses.txt`）。Excel・メモ・AIのリストはロゴなしのHTMLカード、CSVファイルもHTMLで作った。

学び：

- 共有の `kits/mimi-short/app-capture/apply-patch.py` を複数ハンク・複数ファイルに対応させた（従来のパッチもそのまま通る）。
- シミュレーターの「このiPhone内」は `data/Containers/Shared/AppGroup/<group.com.apple.FileProvider.LocalStorage>/File Provider Storage/`。そこに置いたファイルはシステムのファイル選択画面からUIテストで選べる（「ブラウズ」→「このiPhone内」）。
