# 統合プロンプト（完成形を作り直すためのもの。最初の入力の原文ではありません）

Mimiショート（2D公式スタイル、1080×1920、60fps、17.4秒、日本語の吹き出し・字幕＋英語字幕版）。

1. 0–2.6秒：友だち（中央、混乱ポーズ、紙が散らばる）のまわりに「Excel」の表、「メモ」、「AIに作ってもらったリスト」のカードが飛び出す（中身は旅行フレーズ）。吹き出し「覚えたいフレーズ、あちこちにバラバラ…」。
2. 2.6–4.0秒：友だちが左へ、Mimi（右、スマホを見せる）が入る「Excel？メモ？AIのリスト？CSVにしたら…」。3枚のカードが吸い込まれて1つのファイル「CSV 旅行フレーズ.csv」になる。
3. 4.0–5.3秒：実アプリ（シミュレーター）のマイノート「CSVからノートを読み込む」。字幕「マイノートでCSVファイルを選ぶと…」、「CSVファイルを選ぶ」にタップ。
4. 5.3–7.5秒：Mimiのアップ。ファイルが口へ飛び込み、大口 → もぐもぐ。行（英語フレーズ）がくずになって周りに飛ぶ。吹き出し「Mimiが食べるわ！」。
5. 7.5–13.3秒：くずがスマホへ降り、実アプリ：「新しく追加できるノート 12件」→「12件を追加」タップ →「12件を追加しました。」→ マイノートに「旅行 12」（タップ）→ 旅行の一覧 → 復習カード「Could I have the check?」（お手本の声）。字幕はアプリの文言＋「お手本を聞いて、練習・復習」。画面下に「※CSVの読み込みはログインして使えます（画面はテスト用データ）」。
6. 13.3–14.5秒：白いコピーカード「好きな内容を、ここで練習。」。
7. 14.5–16.0秒：友だち（やる気）「自分の好きなフレーズで練習できる！」、Mimi（おなかぽんぽん）「ごちそうさま〜♪」。
8. 16.0–17.4秒：エンドカード「好きな内容を、自分の声のお手本で。」「7日間無料ではじめる」をタップ。

音：テーマBGM、控えめなSFX（もぐもぐはコードで作った紙の音）、CTAタップに pochi。Lancloが読めるのはLanclo用CSVだけ、読み込みはログインが必要。単語帳アプリの名前は出さない。
