# Action Button ① — Add a phrase ("Bless your heart")

**English** · [日本語](README.ja.md)

First of a three-part series on Lanclo's Action Button shortcuts (① Add a phrase, ② Start review, ③ Today's lesson). A friend says "Aww, bless your heart~"; Mimi takes it as praise, presses the Action Button, and a tiny Mimi pops out of the button and pulls the screen open: Add phrase is already there. The app's AI meaning reads 親切にどうも；お気の毒に；おめでたい人だね — the last one is the sting — and Mimi turns on her friend. An example sentence, save, and the phrase goes into review. Closes with "Are you using your Action Button?" and the in-app settings walk.
