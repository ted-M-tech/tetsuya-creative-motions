# 発音のコツ 4 - Milk

[English](README.md)

Lanclo SNSショート #075。「Pronunciation Hacks（発音のコツ）」第4話。ドラフト（2026-10-23、オーナー確認待ち）。15.0秒、1080×1920、60fps、2本（日本語のみ／英語字幕つき）。

コツ：**milk は1音節**。カタカナのミルクは3拍（mi-ru-ku、r と k のあとに母音）。英語の milk は l と k のあとに母音なし。最後の L は暗いL（舌先を上の歯ぐきに、舌の奥を持ち上げる。やわらかい「ゥ」っぽく聞こえることが多い）。

カフェ。1フレーム目から「ミルク、通じない？」、友だちが「Mi-ru-ku, please.」と3拍で注文（オーナーの声・学習者スタイル）。バリスタ姿のミミ（役衣装）は「？？？」。ミミのカード：「ミルクは3拍 / milkは1拍」、赤い拍の丸3つ、足した u に取り消し線（「k のあと 母音なし」）、続いて milk に青い丸1つ、お手本「Milk.」（単語だけのテイク）を舌のヒント「L は舌先を上に / 奥は こもった「ゥ」」の前後に2回。カウンターに戻り友だちが1拍で「Milk, please.」、ミミがミルクを渡す「1拍で → 通じた！」。「次のコツは？」のあとエンドカード。

| 秒 | ビート | 内容 |
|---|---|---|
| 0.00–2.60 | `hook` | 「ミルク、通じない？」、0.3秒に学習者テイク「Mi-ru-ku, please.」（拍ごとに点灯） |
| 2.60–4.20 | `slip` | 「ミ・ル・クの3拍だと…」、ミミが首をかしげて「？？？」 |
| 4.20–5.80 | `tip` | カード：拍の丸3つ、u に取り消し線、「k のあと 母音なし」 |
| 5.80–8.40 | `model` | milk に丸1つ、お手本「Milk.」6.2秒と7.6秒、舌のヒント6.9秒、お手本＝自分の声 |
| 8.40–11.60 | `fix` | 友だち「Milk, please.」、9.6秒にミルク到着「1拍で → 通じた！」 |
| 11.60–13.40 | `cta` | 「次のコツは？」「知りたい発音、コメントで！」 |
| 13.40–15.00 | `end` | エンドカード、14.0秒でCTAタップ |
