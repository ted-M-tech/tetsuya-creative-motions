# 1分で、自分の声をネイティブに（AIボイス設定）

[English](README.md) · **日本語**

友だちがネイティブの英語にうっとり「こうなりたいな〜」→ コピー「1分で、自分の声をネイティブに！」→ Mimiが Lancloの実際の声の登録（声の利用への同意 → 同意を録音 → 声のサンプル 静かな場所で、10〜30秒）を見せる → 同じ文が友だち自身の声で流れて「ぺらぺらじゃん！」→ Mimi「これで練習したらね？」→ エンドカード。18.7秒、1080×1920、60fps。日本語のみ版と英語字幕版の2本。
