# AIと会話、何話そう… — 2D Mimi ショート

[English](README.md) · **日本語**

1フレーム目からフック「AIと会話、毎回『何話そう…』で終わってない？」。ブランドのない一般的なAIチャットの空の入力欄とカーソルの点滅を前に、Mimiが固まる。"Hi!"と送ると「こんにちは！今日は何について話したい？」と聞き返され、「……それを決めてほしいんだけど」。コピー「Lancloなら、話すことはもう用意してある。」のあと、実アプリ（シミュレーター）：ホームに届いている今日のレッスン（デイリーレッスン）、練習タブの会話練習の場面・写真描写の写真・ディベート練習のお題。最後に今日のレッスンでお手本（自分の声）を押し、Mimiが "Please leave the light on." をオーナーの登録済みLanclo音声で話す。「あとは、話すだけ。」「僕、もう迷わない！」

0:17.8 / 1080×1920 / 60fps / 日本語のキャプションと吹き出し、英語1行はオーナー本人の登録音声（`ownvoice.py`、`us`）/ 既存の公式2Dポーズ + GSAP、実アプリ + HyperFrames

2本：日本語のみ（`mimi-topics.mp4`）と英語字幕つき（`mimi-topics-en.mp4`）。完成版はLancloのGoogleドライブ `002.SNS/031. AI Chat Never Knows What to Talk About/`（`Topics_2026-10-21.mp4`、`Topics_EN-subs_2026-10-21.mp4`、素材は `Topics_assets/`）。
