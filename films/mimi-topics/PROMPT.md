# 統合プロンプト（最初の入力の原文ではなく、完成形を作り直すためにまとめたもの）

Lancloの縦型ショート（1080×1920、60fps、約18秒、日本語のみ版と英語字幕版の2本）を、`kits/mimi-short` と `films/mimi-action-review` の型で作る。

- 0–2.4秒（フック、1フレーム目から）：上部キャプション「AIと会話、毎回『何話そう…』で終わってない？」。カメラは空の入力欄の点滅カーソルに寄った状態から0.55秒で引き、ブランドのない「AIチャット」の空の画面と、スマホを持って汗をかくMimi（sheepish）。吹き出し「…」が伸びる。BGMなし、小さなタップ音で間。
- 2.4–4.6秒：Mimiが "Hi!" と送る→入力中…→AI「こんにちは！今日は何について話したい？」→Mimi（stunned）「……それを決めてほしいんだけど」。
- 4.6–5.8秒：白いコピーカード「Lancloなら、話すことはもう用意してある。」（「話すこと」を青）。
- 5.8–13.1秒：右に実アプリ（シミュレーター、QA表示用データ）、左にMimi（point）。ホームのデイリーレッスン →「開いたら、今日のレッスンが届いてる。」、練習タブ→会話練習の場面→写真描写→ディベートのお題、それぞれにチップ「会話の場面」「写真」「ディベートのお題」、キャプション「場面も、写真も、お題も、ぜんぶ用意済み。」
- 13.1–16.6秒：今日のレッスン（"Please leave the light on."）でお手本を押す→オーナーの登録音声（`ownvoice.py`、`us`）で同じ文、Mimiの口が合わせて動く、タグ「お手本 = 自分の声」、キャプション「あとは、話すだけ。」、最後にMimi（confident）「僕、もう迷わない！」。「QA用データ」の講評文は隠す。
- 16.6–17.8秒：エンドカード（「自分の声で、ネイティブの発音を。」「7日間無料ではじめる」、0.45秒後にタップ）。
- 英語字幕は全ての日本語に（下から150px）。エンドカードは "Native pronunciation, in your own voice. / Start free for 7 days."
- 機能・数字はアプリのコードで確かめたものだけ。競合アプリ名は出さない。Mimiの一人称は「僕」。
