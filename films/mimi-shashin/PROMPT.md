# 再制作用の統合プロンプト — 「写真で英語」（実画面の回）

完成版の判断を1つの指示にまとめたものです。最初に入力した原文ではありません（経過は [PROCESS.md](PROCESS.md)）。別の機能で作るときは **[置き換える]** を差し替えてください。

---

LancloのマスコットMimiが**実際のLancloアプリを使う**15秒の縦型ショート（1080×1920、60 fps）を作る。アプリの画面は本物（シミュレーター、QA用デモデータ、個人データなし）、Mimiは承認済みの2Dの絵柄で画面の横に立つ。日本語字幕は上部、スマホは字幕の下から下端約400 pxの手前まで。

## 1. 画面を録る

1. [置き換える：機能] のUIテスト（`native-ios/LancloUITests/<機能>UITests.swift`）を読み、要素のIDと起動引数（`--uitesting --visual-fixtures --qa-<機能>`）を確かめる。
2. 同じクラス名で操作手順のテスト（`DemoWalkthrough.swift`）を書く：起動 → タブ → 機能 → 素材を選ぶ → 録音 → 送信 → 結果をゆっくりスクロール。各画面で1.5〜2.5秒止める。
3. `kits/mimi-short/app-capture/capture.sh` で録画（初回のビルドだけ約7分、以後は約1分）。
4. 録画は可変フレームレート。`cut.sh` で60 fpsにそろえてから、コマ単位で切る。時刻は2コマ/秒のシートで確かめる。
5. 元の録画と切り出しはLancloのGoogle Drive（002.SNS/<NotionのID3桁>. <英語の題>/<回>_assets）へ。

## 2. 話（[置き換える]）

## 3. 組み方

- Mimiは平らな背景（ページと同じ色）で書き出し、編集で縮小して左へ（境目が出ない）。冒頭だけ大きく。
- スマホは時間指定のない入れ物（中の動画だけに時刻を付ける。入れ子の時刻はHyperFramesのエラー）。
- 実画面の文字は小さいので、伝えたい1点は寄りと大きなカードで見せる。字幕はスマホに重ねない。
- 声はアプリのデモデータと同じ文にする（Mimiの答え＝デモの書き起こし、お手本＝デモの改善例）。
