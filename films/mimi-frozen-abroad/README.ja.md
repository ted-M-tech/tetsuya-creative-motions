# 旅先で固まる — ロールプレイ・シリーズ

[English](README.md) · **日本語**

[ロールプレイ — カフェで固まる](../mimi-roleplay/README.ja.md)（17）の続編。冒頭からカードで「カフェで固まった人、手を挙げて。」、カフェのカウンターで氷漬けのMimiが、氷の中で手を挙げる（「はい…」）。続けて Lanclo の会話練習に実在する場面で3連続カチッ：空港のチェックイン（"May I see your passport?"）、ホテルのフロント（"Do you have a reservation?"）、バス（"Hello. Where are you going?"）。スタッフはいつものサブキャラ、アヒルのピッパ（場面ごとに小物だけ変える）。コピー「固まる場面ごと、先に練習。」→ 実アプリ（会話練習 → 空港 → 飛行機の搭乗手続きをする → AIの相手・ヒント・返答・シチュエーション完了）→ 同じ3か所で今度はスラスラ（"Here you are." / "Yes, I have a reservation." / "Does this bus go to the station?"）「もう、固まらない。」→「旅先のどこでも、何度でも。」→ エンドカード。
