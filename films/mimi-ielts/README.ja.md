# IELTSまで1か月 — 毎日1回の模擬試験

[English](README.md) · **日本語**

IELTS本番の1か月前。日めくりカレンダーは「あと30日」、Mimiは「あと1か月しかない…！」。コピー「本番の流れで、毎日1回。」。30日目、Lancloの「スピーキング試験対策 → 模擬試験」で、面接官のMimiがPart 1〜3を順に進め（Part 1 → Part 2 → Part 3）、最後にまとめて振り返る（推定Band「AIによる非公式の目安」と添削「as a software engineer」）。画面下に「AIの練習用フィードバックです（公式スコアではありません）」。そこから日めくりが30→1と加速しながらめくれ、Mimiは自信をつけていく。本番の朝、カレンダーは「本番」、友だち「本番、緊張しない？」、Mimi「1か月、毎日やったし。」→ エンドカード。

16.9秒・1080×1920・60fps。日本語のみ版と英語字幕版の2本。シミュレーター録画（QA用の架空データ）と2DのMimi。声なし（吹き出し）。
