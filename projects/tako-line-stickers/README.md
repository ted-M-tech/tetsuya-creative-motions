# たこ先生 — 毎日つかえる、動く関西弁。

24個をまとめてひとつの完成作品として掲載。

## 再制作する順序

1. 会話の用途を24枠に配分。挨拶・感謝・返答・依頼・就寝・感情が偏らないようにする。
2. セリフ、感情、主動作、構図を制作表にする。
3. 自分が権利を持つキャラクターの基準画像・配色・体型を固定。たこ先生では二腕・下四触手も検証項目にした。
4. 予備動作→主動作→余韻を設計。単純変形、小さな差分、関節動作を使い分ける。
5. 文字は独立レイヤーで後から追加。小さいチャット表示で読めるか確認する。
6. APNGを組み立て、サイズ・容量・フレーム数・ループ時間を提出時点の仕様と照合。
7. 白と濃色の背景で、輪郭・透過・内部の白い部分が欠けていないか確認。数値検査だけで承認しない。
8. 主画像・タブ・表示順を整え、端末で実際の大きさを確認する。

## 再現に必要な入力

自作キャラクターの参照、24枠の用途表、利用許諾のあるフォント、動作ごとの開始・頂点・戻りの絵。生成モデルだけでは同じ完成物になりません。絵の承認と検証を各段階に入れます。

## 記録の根拠

制作時のMOTION-SPEC、PRODUCTION-RULES、商品用APNGから整理した再制作ガイドです。すべての原始プロンプトや商品素材の配布ではありません。
