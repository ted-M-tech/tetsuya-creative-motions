# Landing heading font

Zen Kaku Gothic New Medium, under SIL OFL 1.1 (adjacent license).
Upstream: https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew
Source: ZenKakuGothicNew-Medium.ttf, retrieved 2026-10-07.
The WOFF is a fontTools subset of the text in landing JSX/JS files, used only by the experimental Impeccable headings. Korean uses the system fallback. Approved Lanclo wordmark remains system-ui, weight 400.
Regenerate the character subset when adding heading translations; preserve the upstream license.
