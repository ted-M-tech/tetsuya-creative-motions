# 作品を追加する

1. templates/film/をfilms/作品ID/へコピー。
2. 完成形のPROMPT.md、NARRATION.md、CREDITS.mdと編集ソースを保存。
3. site/posters/に軽いJPGサムネイルを追加。
4. films/catalog.json、ルートREADMEの作品カード、site/index.htmlに追加。
5. MP4はsite/media/または配信先へ。Gitには入れない。
6. npm run check とスマホ幅・PC幅での再生確認を行う。

作品を増やす際も、制作途中の全ログではなく、読者が再利用できる最終判断を残します。実際の入力と後から統合したプロンプトは区別してください。

## 作品と更新版の扱い

作品一覧は企画・プロジェクト単位で1件。改訂版は同じ作品の完成動画を更新し、以前の版は制作ノート内の「制作の変遷」に残す。声や表現を変えた実験は「番外編」にまとめる。カタログのトップレベルは作品のみ、番外編はextras、旧版はhistoryに記録する。異なる企画・目的の映像を作ったときに、新しい作品として追加する。
