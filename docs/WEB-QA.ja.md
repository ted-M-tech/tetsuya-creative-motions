# レスポンシブ確認を再現する

`lp-create`は確認するよう指示するスキルです。ブラウザを動かすのはPlaywrightです。スキルを入れるだけで検証が自動実行されたことにはなりません。

過去のLanclo記録にはChromium/WebKit × JA/EN/KO × 320/390/820/1440pxの24条件、比較表では320/390/430pxの18条件の確認があります。これから使う以下のスクリプトは、その確認方針を公開用に再構成したものです。当時の一時スクリプトそのものではありません。

## 動かす

Node 24以上を使います。リポジトリのルートで、ターミナルA：

```sh
npm ci --prefix projects/lanclo-lp/source
npm run build --prefix projects/lanclo-lp/source
npm run preview --prefix projects/lanclo-lp/source -- --port 4173 --strictPort
```

プレビューの起動を確認してから、別のターミナルB：

```sh
cd tools/web-qa
npm ci
npx playwright install chromium webkit
npm run check -- --url http://127.0.0.1:4173/
```

Linuxでブラウザのシステム依存が足りない場合は、管理する環境の方針に従って `npx playwright install --with-deps chromium webkit` を実行します。ブラウザをダウンロードするためネットワーク・ディスク容量が必要ですが、この確認に有料APIは不要です。

出力はリポジトリの `.local/web-qa/` にあるPNGとreport.json。Git管理対象外です。既定では24条件を確認します。

別サイトの日本語だけを確認する例：

```sh
npm run check -- --url http://127.0.0.1:4321/ --locales ja --widths 390,1440
```

ローカルプレビュー専用です。ページを信頼できる環境で動かしてください。言語は `?lang=` を付けて切り替えます。別方式のサイトではルートを指定するなど、対象に合わせて調整してください。report.jsonには要求言語と実際のhtml langを記録しますが、翻訳内容が正しいかは自動判定しません。

## 自動で見るもの

- ページが正常に開き、JavaScript例外が出ないこと。
- ページ全体と表示中の比較表セルに横溢れがないこと。
- スクロール後に画像をデコードできること。
- reduced motion設定下の全ページ画像、見出し、言語、各条件の結果を保存。

失敗時は終了コード1。画像の良し悪し、自然な日本語、文言の重複、すべての要素の重なりまでは自動判定しません。カルーセルなどの意図的な切り抜きは画像で判断します。

## 画像・操作で見るもの

| 対象 | 確認すること |
|---|---|
| 390pxとノートPC | 主題が読める、ヒーローの密度、見出しの自然な改行、画像の意味 |
| 320pxと中間幅 | ナビ・価格・比較表が欠けない、本文が小さすぎない |
| 通常の動き | スクロールで内容が出る、アニメーションのテンポ、動画の読込・再生・シーク |
| reduced motion | 動きが減り、説明や導線が消えない。自動スクリプトは設定を与えるだけで停止を保証しない |
| キーボード | Tabの順番とフォーカス、Enter、ダイアログがあればEscapeとフォーカス復帰 |
| リンクと表示内容 | CTAの行先、価格・予定・デモ表示、多言語の欠落 |

通常の動きとキーボード操作は今回の自動スクリプトには含めていません。必要な操作シナリオは作品のテストへ追加してください。まずモバイルとPCをまとめて見て、見つかった問題を直し、該当条件で再確認します。

Playwrightのviewportは実端末ではありません。WebKitはSafariと同じエンジン系列ですが、実機のOS、音声、タッチ、アドレスバー、省電力状態まで検証したことにはなりません。実機が必要な機能は別に確認し、検証範囲を記録します。
