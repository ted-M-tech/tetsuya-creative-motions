# 3Dキャラクター制作ガイド

[English](3D-CHARACTER-WORKFLOW.md) · **日本語**

2Dのキャラクターを3Dにし、その3Dキャラクターでショートアニメを作るための手順です。Mimi（Lanclo）で実際に通した流れと、そこで分かったことをまとめています。個別の記録は [films/mimi-3d](../films/mimi-3d/PROCESS.md)、そのまま渡せる指示は [films/mimi-3d/PROMPT.md](../films/mimi-3d/PROMPT.md) を見てください。

## 方針

- **キャラクターは3Dで一度だけ作り、毎回呼び出す**。AI動画で毎回キャラクターを生成すると、ロゴや模様、耳の色などの細部が崩れる。参考にした韓国のソフビ風ショート（Hyungmeme）も、形が崩れないことから3D CGと判断した。
- **全部スクリプトで作る**。Blenderをヘッドレスで動かし、同じスクリプトから同じモデルが再生成できるようにする。画面での調整はMCPで行い、結果はスクリプトに戻す。
- **2つのAIで役割を分ける**。Claude Codeが組み立て・描画・判断、Codex（`codex-p`）が参照画像の生成とレビュー。

## 道具

| 道具 | 役割 | 入れ方 |
|---|---|---|
| Blender 5.2 LTS | モデル、骨組み、描画（Cycles / EEVEE） | `brew install --cask blender` |
| mcp-for-blender | ClaudeとCodexから、起動中のBlenderを見ながら操作 | `claude mcp add --scope user blender -- uvx mcp-for-blender`、`codex-p mcp add blender -- uvx mcp-for-blender`、`uvx mcp-for-blender install-addon` のあとBlenderで有効化し「Start MCP Server」 |
| blender-production-skills | 背景・シーン作り、交差チェックの作法 | GitHub `XliuXjianX/blender-production-skills` をcloneし、各スキルを `~/.claude-personal/skills` と `~/.codex-personal/skills` にリンク |
| Codex（`codex-p`） | 参照画像の生成、アートディレクターとしてのレビュー | `codex-p exec --image a.png,b.png - < prompt.txt`（プロンプトは標準入力で渡す） |
| HyperFrames | 字幕・テロップ・音・締めの編集 | Claudeはhyperframes系スキル、Codexは公式 `hyperframes` プラグイン |
| ImageMagick / ffmpeg | 比較画像、連番の動画化 | `brew install imagemagick ffmpeg` |

自動セットアップ（`uvx mcp-for-blender setup`）は、Cursorなど関係ないツールの設定にも追記するので使わない。

検討して見送ったもの：img2threejs（画像からコードで3Dを組む、段階ごとの検証つき。出力がThree.jsなので、Webで3Dキャラを動かすときに使う）、画像から3Dを生成するAI（Meshy、Tripo、Hunyuan3D。面の構造が粗く、部品を分けられないので下絵止まり）。

## 手順1：キャラクターの正本を作る

1. **参照画像**：元のイラストから、画像生成AIで三面図と「仕上がり見本」を作る。見本を依頼者に確認してもらい、目標として固定する。
2. **形**：楕円体を組み合わせて結合し、ボクセルで再構成→スムージングで1つの塊にする。小物は別部品。
3. **顔**：目・鼻・口は顔の表面に光線を飛ばして置く。ほっぺや耳の内側のような平らな模様は、シェーダーで塗る。
4. **骨組み**：体・頭・耳・腕など最小限。体は自動ウェイト、顔と小物は頭の骨に固定。
5. **交差チェック**：BVHで部品同士の交差を数値で出し、0を確認する。
6. **レビューの往復**：下の「レビューの回し方」で合格（SHIP）まで回す。
7. **正本化**：`.blend`、スクリプト、4方向の画像、識別の決まりを正本の場所に置く。Mimiの正本はLanclo本体リポジトリの `design/mimi-3d/`。

## 手順2：ショートアニメを作る

| 工程 | やり方 |
|---|---|
| 絵コンテ | 10〜30秒、4〜6カット。日常の「あるある」から少し大げさに広げる |
| 背景・小物 | blender-production-skillsでシーンを組む。遠景や看板はCodexの画像、汎用素材はPoly Haven |
| 演技 | 決まった動き（跳ぶ、耳が揺れる、驚く、手を振る）は関数にして使い回す。細部はMCPで画面を見ながら直す |
| 描画 | 決めカットはCycles、それ以外は高速なEEVEE。夜間に一括で回す |
| 編集 | HyperFramesで字幕・音・Lanclo等の締めを付ける。テンプレートにして毎回差し替える |
| 派手なカット（任意） | Blenderで描いたキャラクターを参照画像にして、AI動画で作る |

## レビューの回し方

1. 判断者（Claude）が直して描画し、「目標｜現在」を横に並べた画像を作る。
2. Codexに、その画像とスクリプトを渡す。指示：厳しめのアートディレクターとして、差の大きい順に最大6つ、関数名と数値つき、確信度つき、残すべき点も。出荷できるなら1行目に「SHIP」。
3. 判断者が採否を決めて反映し、交差チェックをしてから次の往復へ。

守ること：

- **依頼者の決定はレビューの指示文に書く**（例：体を細くしない）。書かないと覆される。
- **提案が2回反転したら固定する**。Mimiでは構図の角度、光、手の大きさが往復した。判断者が値を決め、「固定済み・壊れていない限り触れない」と書く。
- **コードも読ませる**。Mimiでは座標の取り違えと、上限の効いていない計算という実際のバグを2つ見つけた。
- 1往復は `scripts/review_round.sh` 1本で回る（描画→比較画像→Codex→指摘の保存）。

## 描画の設定（Mimiで決まった値）

- Cycles（GPU/Metal）、表示はStandard＋露出補正（AgXはブランドの青の彩度を落とした）
- 継ぎ目のないスタジオ背景、大きなキー＋弱いフィル＋リム。背景と照明はカメラと一緒に回す
- 試し：解像度40〜60%、24〜64サンプル。本番：160サンプル、1080×1920で1枚約30秒（M5 Pro）
- 背景を明るくしすぎると、床の照り返しで白いキャラクターの下半分が飛ぶ

## よくある失敗

| 症状 | 原因と対処 |
|---|---|
| Codexにプロンプトが渡らない | `-i` が後続の引数を画像として読む。`--image a,b` と標準入力にする |
| 白が真っ白に飛ぶ／灰色になる | Cycles移行時は光と露出を作り直す。低解像度で露出だけ先に合わせる |
| 小物がキャラクターを貫通する | 回転の符号ミスなど。交差チェックで数値確認 |
| 模様に穴や階段状の縁 | 平らな板を曲面に貼る・面を切り出すのをやめ、シェーダーで塗る |
| 顔に生気がない | 目を大きく下寄り・離し気味、光の映り込みを1つ、ほっぺはぼかしすぎない |
| 腕を上げると肩が伸びる | 自動ウェイトの限界。演技のアップの前にウェイトを手で調整 |

## 置き場所の決まり

- **正本**：キャラクターの持ち主のリポジトリ（Mimiなら `native-voice-clone/design/mimi-3d/`）。`.blend`、スクリプト、承認済みの画像、識別の決まり。
- **公開記録**：このリポジトリの `films/<id>/`。過程、実際のプロンプト、レビュー原文、途中経過の画像、ソースの写し。
- 描画結果（`renders/`）はGitに入れない。
