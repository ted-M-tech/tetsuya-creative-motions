# この制作フローを使って動画を作る

[English](VIDEO-WORKFLOW.md) · **日本語**

完成動画だけでなく、構成・改善・記録の進め方も共有します。専用スキルは [tetsuya-creative-motions](../skills/tetsuya-creative-motions/SKILL.md)。構成や演出の判断を支えるもので、これだけで動画生成APIやレンダラーが使えるようになるわけではありません。

## 3層で管理する

| 層 | 役割 | 保存場所 |
|---|---|---|
| 制作ツール | レンダリング、動き、素材、音声ミックス | インストール済みの技術スキル |
| 自分の制作フロー | 構成の維持、修正範囲、正確な表現、制作記録 | `skills/tetsuya-creative-motions/` |
| 作品 | ブランド、台本、声、研究、素材、ソース | `films/<project>/` と `styles/` |

LancloはHyperFramesと、その動画構成・アニメーション・音声・素材スキルで制作しました。それらをこのスキル内に複製せず、提供元の手順で別途導入します。音声生成は自分のAPIアクセスが必要で、料金が発生する場合があります。企画・台本・記録の作成は、音声APIなしでも進められます。

## 導入

リポジトリをcloneし、スキルのフォルダ全体を、利用するエージェントが読むユーザースキルの場所へコピーします。同名の既存スキルがある場合は、上書きせず先に差分を確認してください。

`~/.agents/skills/`を読む環境の例：

```sh
git clone https://github.com/ted-M-tech/tetsuya-creative-motions.git
cd tetsuya-creative-motions
mkdir -p ~/.agents/skills
# コピー先に同名フォルダがないことを確認して実行
cp -R skills/tetsuya-creative-motions ~/.agents/skills/
```

Codexで`CODEX_HOME/skills`または`~/.codex/skills`を使う環境なら、その保存先に合わせます。導入後は必要に応じて新しいセッションを開いてください。GitHubに置いただけで全員のエージェントへ自動登録されるわけではありません。`SKILL.md`の場所を直接指定して読む方法もあります。

自分でこの原本を管理する場合は、コピーを二重管理せず、リポジトリ直下でリンクする方法も使えます。

```sh
# リンク先に同名ファイル・フォルダがない場合のみ
ln -s "$PWD/skills/tetsuya-creative-motions" ~/.agents/skills/tetsuya-creative-motions
```

スキル本文はMarkdownですが、実際の生成やレンダリングには利用環境のツールが必要です。構造検証は実施済みで、全エージェント・全音声サービスでの動作を保証するものではありません。

## 依頼例

**新しい動画の企画**

> $tetsuya-creative-motions を使って、美容室向け予約アプリの45秒動画を考えて。予約調整がラクになることを伝えたい。まず構成とセリフを見せて。まだ音声生成・レンダリングはしないで。

**既存動画の改善**

> $tetsuya-creative-motions を使って、分析から次のレッスンへのつながりを改善して。承認済みの冒頭・研究の説明・声・締めは維持。変更内容を整理して、合意した範囲を反映して。

**完成後の記録**

> $tetsuya-creative-motions を使って、完成版の台本、統合プロンプト、実際の音声生成入力、タイムライン、出典、ソースをまとめて。声を変えた版は番外編へ。作品集への掲載内容をローカルで用意して、まだ公開しないで。

許可する作業範囲は依頼に合わせます。スキルを呼んだだけで課金や公開への許可が増えるわけではありません。

## 更新方針

原本はこのGitHubで管理します。繰り返し使える判断だけスキルへ、色・声・秒数など作品固有の選択は作品フォルダへ残します。上流の技術スキルは別途更新し、完成作品の依存バージョンは固定して記録します。詳細は[記録のルール](../skills/tetsuya-creative-motions/references/project-records.md)。
