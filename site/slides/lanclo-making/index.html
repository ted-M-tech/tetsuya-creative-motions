01 / 08

伝わるLPは、
判断でできている。

Lancloの制作を振り返る8枚。今回新しくまとめた制作解説。

02 / 08

機能より先に、
欲しかった変化。

「自分の声がお手本になる」を主役に。仕組みはその次に見せる。

03 / 08

3ステップなら、
3つの絵で。

録音 → 自分の声のモデル → 発音。文章を重ねず、読む順番と同じ順番で見せる。

04 / 08

画像に、
役割を持たせる。

練習の説明はunDraw。ニュースのジャンルは写真。素材を無差別に混ぜない。

05 / 08

数字は大きく。
意味は正確に。

約1.3倍は、外部研究の得点上昇幅の比。製品そのものの効果と混同しない。

06 / 08

小さな画面で、
最後まで確かめる。

見出しの改行、比較表、画像、操作。デスクトップの縮小版で終わらせない。

07 / 08

プロンプトだけで、
終わらせない。

依頼の抜粋 / 再構成した指示 / ソース / 依存関係 / 出典 / 検証を一緒に残す。

08 / 08

次は、
あなたの作品へ。

ブランドと事実を差し替え、判断の手順を使ってみる。公開ソースから始められます。
